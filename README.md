# 창가의 고양이

화면을 창문 삼아 그 너머 아늑한 방에 사는 고양이 한 마리. 버튼도, 메뉴도 없습니다. 앱을 열면 lofi 느낌의 픽셀아트 방에서 고양이가 자고, 기지개를 켜고, 그루밍을 하고, 방을 거닐다 창가(화면) 앞으로 와서 당신을 봅니다. 손가락으로 쓰다듬고 밥과 물을 챙기며 서로 믿음을 쌓아 갑니다.

방은 실제 시각을 따라갑니다. 해는 아침에 왼쪽에서 떠서 저녁에 오른쪽으로 지고, 창살 그림자를 품은 햇빛 조각이 바닥을 가로질러 갑니다(고양이는 가끔 그 햇살 자리에 가서 한참 누워 있어요). 해질녘엔 방이 금빛으로, 노을엔 분홍빛으로 물들고, 밤에는 램프와 꼬마전구·초가 켜지고 창밖 도시의 창문에 불이 들어옵니다. 가끔 몇 시간씩 비가 오면 하늘이 낮게 잿빛이 되고 유리창에 물방울이 맺혀 흘러내리며, 낮에도 램프가 켜지고 빗소리가 들립니다. 창턱의 라디오는 lofi 음악을 틀어 줍니다(톡 누르면 끄고 켜기). 창 너머로는 낮엔 먼 새소리(새벽과 봄에 더 많이), 여름·초가을 밤엔 귀뚜라미 소리가 유리창에 걸러져 들려요. 창밖 나무는 실제 날짜를 따라 4월엔 벚꽃, 여름엔 짙은 초록, 가을엔 노랗고 붉게 물들었다 지고, 겨울엔 비 대신 눈이 내려 지붕에 쌓여요. 낮에 비가 그치면 한동안 창밖 도시 위로 무지개가 떠요. 봄·가을엔 며칠에 한 번 새벽부터 아침까지 안개가 끼어, 먼 언덕과 도시가 뿌옇게 사라지고 햇빛이 부드럽게 번져요. 여름엔 비가 천둥번개로 바뀌기도 해요: 번개가 치면 창밖 하늘이 번쩍 밝아지며 가끔 도시 너머로 번개 줄기가 내리꽂히고, 방에도 차가운 빛이 순간 들어와요. 몇 초 뒤(멀수록 늦고 작게) 유리창 너머로 천둥이 울리면 고양이가 움찔하며 창 쪽을 보고, 가까운 천둥에는 털을 세우거나 상자나 침대로 숨기도 해요. 아침엔 왼쪽에서 해가 떠오르고, 저녁엔 해가 언덕 위에 걸렸다가 붉게 저물어요. 하늘엔 뭉게구름이 바람에 천천히 흘러가고(구름 양은 날마다, 시간마다 달라요), 해가 낮을 땐 구름 밑이 분홍·금빛으로 물들어요. 밤엔 창 왼쪽 위에 실제 그날 밤의 달(초승달·반달·보름달)이 달무리를 두르고 뜨고, 달이 찬 만큼 달빛이 창살 그림자와 함께 바닥에 내려앉아요. 10월엔 창턱에 작은 호박이 놓이고, 핼러윈 주간(10/24~11/1)엔 얼굴이 새겨져 밤마다 안에서부터 빛나요.

- `index.html` — 픽셀아트 고양이(3D 모델을 픽셀아트로 그림). 이 앱이 본편입니다.
- `painted.html` — 처음 만든 그림 고양이(한 장의 그림을 변형해 움직임).

## 고양이와 지내는 법

| 하고 싶은 것 | 하는 법 |
| --- | --- |
| 쓰다듬기 | 고양이 위를 손가락으로 천천히 쓸기. 털 결(머리 → 등 → 꼬리) 방향이 좋아요 |
| 부르기 / 관심 끌기 | 빈 곳을 톡 두드리기, 두 번 두드리면 노크 |
| 같이 놀기 | 털실 공을 손가락으로 잡고 바닥 위로 끌기 (톡 치면 굴러가요) |
| 사료 주기 | 휴대폰 흔들기 (사료 봉지 소리), 또는 빈 곳을 좌우로 빠르게 문지르기 |
| 물 주기 | 빈 곳을 길게 누르고 있기 (누르는 동안 물이 따라져요) |
| 화장실 모래 치우기 | 빈 곳을 아래로 쓸어내리기 |
| 작별 인사 / 새 고양이 | 숨을 멈춘 고양이를 오래 누르기 → 빈 창가를 오래 누르기 |
| 음악 끄기 / 켜기 | 창턱의 라디오를 톡 누르기 (상태를 기억해요) |
| 크레딧 보기 | 창턱의 작은 그림 액자를 톡 누르기 |

필요한 순간에만 화면 아래에 옅은 안내 문장이 잠깐 나타납니다. 데스크톱에서는 `F`(사료), `W`(누르고 있으면 물), `L`(모래)도 됩니다.

## 고양이의 마음

- **부위별 호불호**: 턱·볼·머리·목덜미는 좋아하고, 꼬리·발·배는 싫어해요. 고양이마다 성격(좋아하는 부위, 참을성, 목소리)이 조금씩 다릅니다.
- **결과 속도**: 털 결을 거스르거나 너무 빠르게 문지르면 싫어하고, 거슬러 쓴 털은 한동안 헝클어진 채 남아요.
- **과자극**: 좋아하는 곳도 너무 오래 만지면 꼬리 끝이 까딱이고, 등 가죽이 꿈틀거리고, 귀가 젖혀지다 결국 하악질과 솜방망이, 그래도 계속하면 도망갑니다.
- **기분이 좋으면** 골골송(소리 + 지원 기기에서는 진동), 눈을 지그시 감기, 손에 머리를 기대기, 꾹꾹이, 천천히 눈 깜빡이기(고양이식 애정 표현).
- **신뢰도**는 모든 접촉으로 조금씩 변해요. 낮으면 잘 놀라고 경계하며 하악질이 빨라지고, 높으면 먼저 다가와 트릴로 인사하고 알림으로 당신을 부릅니다.
- **잠**: 대부분 자고, 가끔 실눈을 떠서 당신을 확인하고, 한숨을 쉬고, 귀를 움찔해요. 새벽과 해질녘에 더 활발합니다.
- **눈**: 그림 위에 실시간으로 그려지는 눈이 당신(화면)을 보거나 손가락을 따라가요. 동공은 빛·흥분·공포에 따라 커지고 줄어들고, 눈동자에는 이 창(화면)이 비쳐요.

## 고양이의 하루

- 침대에서 자고, 깨면 기지개·하품·그루밍을 하고, 방을 돌며 몬스테라 화분·라디에이터·털실·책 더미의 냄새를 맡아요.
- 해가 들면 가끔 바닥의 햇살 자리에 가서 한참 누워 있어요. 해가 움직여 누운 자리가 그늘이 되면 일어나 햇살을 따라 자리를 옮겨요. 난방철(10월 말~4월 초)엔 라디에이터 앞 바닥에 가서 몸을 녹이며 한참 엎드려 있기도 해요. 햇살 자리나 라디에이터 앞에서 졸음이 오면 침대로 가지 않고 그 자리에서 잠들었다가, 깨면 잠시 뒤 침대로 돌아가요.
- 기분이 좋으면 털실 공을 가지고 놀아요: 낮게 엎드려 노려보다 엉덩이를 씰룩이고 덮친 뒤 앞발로 툭툭. 공을 톡 치면 굴러가고, 깨어 있으면 쫓아가요.
- 손가락으로 털실 공을 끌면 고양이 눈과 고개가 공을 따라가요. 멀어지면 달려가고, 움직이면 덮치고, 가까이 스치면 앞발로 후려쳐요. 잡히면 두 앞발로 꾹 누르고 깨물어서, 손가락을 당겨도 잠깐 빠져나오지 않아요(진동이 오는 기기에서는 손끝에 느껴져요). 계속 놀아 주면 지칠 때까지 놀고, 노는 동안은 잠들지 않으며 외로움이 줄어요.
- 밤엔 가끔 나방이 램프 주위를 팔랑팔랑 맴돌고, 따뜻한 계절 낮엔 파리가 창가를 윙윙 날다 창턱이나 유리에 앉아요. 고양이는 고개로 쫓으며 이빨을 딱딱거리고(채터링), 낮게 내려앉으면 살금살금 다가가 뒷다리로 일어서서 앞발로 후려쳐요.
- 가끔 앞발을 핥아 얼굴과 귀를 문지르며 세수를 해요. 울 때는 소리에 맞춰 입이 움직여요(소리를 꺼도요).
- 창턱에 뛰어올라 창밖을 봐요. 밤에는 도시 불빛을 보러 더 자주 올라가고, 그러다 졸리면 창턱 위에 식빵 자세로 엎드려 잠들어요(깨면 한동안 밖을 보다 내려와요). 비 오는 날엔 유리창을 타고 흘러내리는 빗방울을 고개로 따라가며 앞발로 톡톡 건드려요. 꼬리를 창턱 아래로 늘어뜨리고, 새가 지나가면 고개로 쫓으며 이빨을 딱딱거려요(채터링). 비 오는 날 더 자주 올라가요.
- 가끔, 특히 해 질 녘과 밤에 갑자기 우다다를 해요. 엉덩이를 씰룩이다 꼬리를 세우고 침대 앞을 지그재그로 휙휙 내달리고(급히 꺾을 때 발톱이 바닥을 긁어요), 길에 털실이 있으면 차서 날려 버리고 그대로 털실 사냥에 나서기도 해요. 실컷 달리면 미끄러지듯 멈춰 당신 쪽을 보고 앉아, 아무 일 없었다는 듯 두리번거려요.
- 사흘씩 번갈아 방 한쪽에 빈 종이 상자가 놓여요(들어가면 맞는 거예요). 고양이는 다가가 안을 들여다보고 폴짝 뛰어 들어가, 몸을 돌려 머리만 내민 채 식빵 자세로 앉아 있다가 그대로 졸기도 해요. 다 쉬면 몸을 돌려 폴짝 나와요.

## 생활과 건강

실제 시간으로 흘러갑니다. 앱을 닫아 둔 동안에도 고양이는 배고파지고, 밥을 먹으러 가고, 화장실을 쓰고, 돌아다닙니다.

- 가득 찬 밥그릇은 하루쯤 갑니다. 그릇이 비고 배가 고프면 당신을 보며 웁니다.
- 밥과 물을 전혀 주지 않으면 약 2일 뒤 아프기 시작하고(색이 바래고, 호흡이 얕아지고, 반응이 줄어요) 약 3~4일 뒤 죽습니다. 다시 챙겨 주면 회복해요.
- 더러운 화장실은 쓰지 않으려 하고, 다른 곳에 실수를 하며 당신을 덜 믿게 됩니다.
- 기분이 상해 도망가면 몇 분에서 수십 분 뒤 돌아와요. 발소리가 먼저 들립니다.
- 밥그릇·물그릇·화장실은 방 안에 있어서, 고양이가 걸어가 먹고 마시고 나가는 모습이 보이고 그릇이 줄어듭니다. (그림 고양이에서는 창밖이라 소리로만 전해집니다.)

## 알림

앱이 닫혀 있는 동안 고양이가 필요로 할 것을 미리 계산해 알림을 예약합니다(배고픔, 물, 화장실, 아픔, 외로움). 밤 11시~아침 8시에는 위급할 때만 울립니다.

- **네이티브 앱(권장)**: Capacitor 로컬 알림으로 앱이 꺼져 있어도 정확히 옵니다.
- **웹/PWA**: 브라우저가 백그라운드 탭을 살려 두는 동안만 보낼 수 있습니다. 확실한 알림은 네이티브 빌드에서 쓰세요.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173  (?hour=22 밤의 방, ?rain=1 비 오는 방, painted.html 은 그림 고양이)
npm test           # 생존/알림 예측 시뮬레이션 테스트
npm run build      # dist/ 에 정적 사이트 (PWA)
```

### 폰 앱으로 빌드 (iOS / Android)

```bash
npm run build
npx cap add android      # 또는: npx cap add ios  (macOS + Xcode 필요)
npx cap sync
npx cap open android     # Android Studio 에서 실행/서명
```

Android 알림 아이콘으로 `android/app/src/main/res/drawable/ic_stat_cat.png`(흰색 실루엣)를 넣으면 됩니다. `public/icons/badge-96.png`를 그대로 써도 됩니다.

`tools/build_layers.py`가 원본 그림 한 장을 배경과 분리하고, 몸·꼬리 끝·머리·양쪽 귀 레이어로 나누고, 움직일 때 드러나는 부분(턱 밑, 귀 뒤, 꼬리 아래)을 채워 `public/assets/`에 내보냅니다. 다른 그림으로 바꾸려면 이 스크립트의 다각형과 `rig.json` 기준점을 새 그림에 맞추면 됩니다.

## 알아 둘 점

- **그림 저작권**: 지금 고양이는 첨부해 주신 그림을 그대로 씁니다. 그림은 다른 작가의 작품일 수 있으니, 앱을 공개 배포하기 전에 사용 권리를 확인하거나 직접 그리거나 의뢰한 그림으로 바꿔 주세요.
- **그림 고양이의 움직임 한계**: 그림이 한 장(웅크려 자는 자세)뿐이라 걷기·먹기 자세는 그리지 않았습니다. 떠날 때는 휙 사라지고(모션 블러), 돌아올 때는 초점이 맞듯 나타나며, 밥·물·화장실은 창밖 소리로 표현합니다. 같은 화풍의 추가 자세 그림이 있으면 같은 방식으로 리그에 붙일 수 있어요.
- **3D 고양이 모델 출처**: 픽셀아트 고양이는 guillaume bolis의 ["3d modelling my cat: Fripouille"](https://sketchfab.com/3d-models/3d-modelling-my-cat-fripouille-0ab14bf98e754f8d90fe1bf1c84ca66c) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))을 우리 뼈대에 다시 리깅하고, 털을 픽셀아트용 몇 가지 평면 색으로 단순화하고(등의 태비 줄무늬를 띠로 이음), 눈을 절차적 눈으로 바꿔서 씁니다. 앱을 배포할 때는 앱 안 크레딧에도 이 출처와 "수정함"을 적어야 합니다. 변환은 `tools/cat3d/fripouille.py`가 하고(`public/cat3d/fri.bin`), 픽셀용 털 재질만 다시 만들 때는 `tools/cat3d/recoat.py`를 씁니다. 출처 문구는 파일 머리에도 들어 있습니다.
- **소리**는 모두 실시간 합성이라 실제 녹음보다 덜 사실적일 수 있습니다. `src/audio/audio.ts`의 뱅크를 녹음 파일로 바꿀 수 있습니다.
- iOS Safari는 웹 진동을 지원하지 않아 골골송 진동은 Android 브라우저와 네이티브 앱에서만 느껴집니다.
