# 창가의 고양이

화면을 창문 삼아 그 너머 아늑한 방에 사는 고양이 한 마리. 버튼도, 메뉴도 없습니다. 앱을 열면 lofi 느낌의 픽셀아트 방에서 고양이가 자고, 기지개를 켜고, 그루밍을 하고, 방을 거닐다 창가(화면) 앞으로 와서 당신을 봅니다. 손가락으로 쓰다듬고 밥과 물을 챙기며 서로 믿음을 쌓아 갑니다.

방은 실제 시각을 따라갑니다. 해는 아침에 왼쪽에서 떠서 저녁에 오른쪽으로 지고, 창살 그림자를 품은 햇빛 조각이 바닥을 가로질러 갑니다(고양이는 가끔 그 햇살 자리에 가서 한참 누워 있어요. 기분 좋은 날엔 눕기 전에 털썩 옆으로 쓰러져 배를 하늘로 드러내고, 앞발을 가슴에 오므린 채 등을 바닥에 비비며 이리저리 뒹굴다가 그대로 쭉 뻗어 햇살 낮잠에 들어요). 해질녘엔 방이 금빛으로, 노을엔 분홍빛으로 물들고, 밤에는 램프와 꼬마전구·초가 켜지고 창밖 도시의 창문에 불이 들어옵니다. 새벽 1시쯤이면 집주인이 잠자리에 든 듯 램프가 꺼지고, 꼬마전구만 켜 둔 방은 푸른 달빛에 잠겨요(6시쯤 다시 램프가 켜져요). 그 어둠 속에서 고양이가 눈을 뜨고 있으면 눈동자가 녹황색으로 은은하게 빛나요. 가끔 몇 시간씩 비가 오면 비가 들기 시작할 때부터 무거운 잿빛 구름층이 도시 위로 낮게 내려앉아요(머리 위 구름은 크고 어둡게 빨리, 먼 구름은 작고 옅게 천천히 흘러가고, 그 밑으로 찢어진 조각구름이 바람에 휙휙 지나가요. 지평선 쪽엔 밝은 하늘이 한 줄 남고, 밤엔 도시 불빛이 구름 밑을 은은하게 물들여요). 유리창엔 물방울이 맺혀 흘러내리며, 낮에도 램프가 켜지고 빗소리가 들립니다. 비 오는 밤엔 젖은 유리 너머로 건너편 창문 불빛이 동그랗게 번져 보여요. 창턱의 라디오는 lofi 음악을 틀어 줍니다(톡 누르면 끄고 켜기). 곡마다 조와 빠르기, 코드 진행, 드럼의 느낌(가끔은 느긋한 하프타임)이 달라서 오래 틀어 둬도 같은 곡이 이어지지 않고, 곡이 끝나면 마지막 화음이 길게 울린 뒤 레코드 잡음만 잠깐 나다가 다음 곡이 피아노부터 시작돼요. 음악이 흐르는 동안 깨어서 느긋하게 쉬는 고양이는 가끔 몇 마디 동안 꼬리 끝을 박자에 맞춰 까딱까딱해요. 음악을 켜 두고 한참(40~55분) 아무것도 만지지 않으면, 공부나 일하는 사람 키보드를 밟는 고양이처럼 당신 바로 앞으로 와서 트릴 소리로 당신을 부르고 앞발을 뻗어 톡 쳐요(졸고 있었으면 기지개부터 켜고 와요). 손가락을 대 주면 같이 놀고, 대답이 없으면 그냥 당신 바로 앞에 엎드려 한동안 곁에 있어요. 창 너머로는 낮엔 먼 새소리(새벽과 봄에 더 많이), 여름·초가을 밤엔 귀뚜라미 소리가 유리창에 걸러져 들려요. 창밖 나무는 실제 날짜를 따라 4월엔 벚꽃(꽃이 질 무렵엔 꽃잎이 하나둘 바람에 날려요), 여름엔 짙은 초록, 가을엔 노랗고 붉게 물들었다 지고(잎이 성글어질 무렵엔 낙엽이 한 장씩 바람에 실려 떨어져요), 겨울엔 비 대신 눈이 내려 지붕에 쌓여요. 낮에 비가 그치면 한동안 창밖 도시 위로 무지개가 떠요. 봄·가을엔 며칠에 한 번 새벽부터 아침까지 안개가 끼어, 먼 언덕과 도시가 뿌옇게 사라지고 햇빛이 부드럽게 번져요. 여름엔 비가 천둥번개로 바뀌기도 해요: 번개가 치면 창밖 하늘이 번쩍 밝아지며 가끔 도시 너머로 번개 줄기가 내리꽂히고, 방에도 차가운 빛이 순간 들어와요. 몇 초 뒤(멀수록 늦고 작게) 유리창 너머로 천둥이 울리면 고양이가 움찔하며 창 쪽을 보고, 가까운 천둥에는 털을 세우거나 상자나 침대로 숨기도 해요. 당신을 믿는 고양이라면 비가 계속되는 동안 조금 있다가 슬그머니 나와서 당신 바로 앞, 곁에 와서 엎드려요(곁에 와 있을 땐 다음 천둥에도 움찔만 하고 도망가지 않아요). 아침엔 왼쪽에서 해가 떠오르고, 저녁엔 해가 언덕 위에 걸렸다가 붉게 저물어요. 하늘엔 뭉게구름이 바람에 천천히 흘러가고(구름 양은 날마다, 시간마다 달라요), 해가 낮을 땐 구름 밑이 분홍·금빛으로 물들어요. 맑은 날 해가 들 땐 가끔 건너편 건물의 창문이 열리며 반사된 햇빛 조각이 방바닥을 쓱 가로질러 가요. 깨어 있는 고양이는 고개로 그 빛을 따라가고, 장난기가 돌면 레이저 점처럼 쫓아가 덮치고는 사라진 자리를 두리번거려요. 맑은 낮엔 가끔 하늘 높이 비행기가 햇빛에 반짝이며 지나가고, 뒤로 그어진 하얀 비행운이 한참 남았다가 천천히 퍼지며 사라져요(해 질 녘엔 분홍·금빛으로). 밤엔 창 왼쪽 위에 실제 그날 밤의 달(초승달·반달·보름달)이 달무리를 두르고 뜨고, 달이 찬 만큼 달빛이 창살 그림자와 함께 바닥에 내려앉아요. 맑은 밤엔 아주 가끔 별똥별이 꼬리를 그으며 떨어지고, 깨어 있던 고양이는 귀를 쫑긋 세우고 창을 올려다봐요. 10월엔 창턱에 작은 호박이 놓이고, 핼러윈 주간(10/24~11/1)엔 얼굴이 새겨져 밤마다 안에서부터 빛나요.

- `index.html` — 픽셀아트 고양이(3D 모델을 픽셀아트로 그림). 이 앱이 본편입니다.
- `painted.html` — 처음 만든 그림 고양이(한 장의 그림을 변형해 움직임).

## 고양이와 지내는 법

| 하고 싶은 것 | 하는 법 |
| --- | --- |
| 쓰다듬기 | 고양이 위를 손가락으로 천천히 쓸기. 털 결(머리 → 등 → 꼬리) 방향이 좋아요. 아직 낯선 고양이는 머리와 볼을 가장 좋아해요(처음 열면 고양이는 깨어 침대에서 당신을 보고 있고, 첫 안내도 그쪽을 알려 줘요). 손을 대면 화면이 고양이 쪽으로 가까이 다가가는데, 손가락이 닿은 곳은 손가락 아래에 그대로 머물러요(두 손가락으로 확대할 때처럼). 손에 반응하는 고양이 얼굴은 늘 화면 안에 남도록, 그만큼만 다가가요(필요하면 털이 손가락 아래로 조금 미끄러져요). 고양이가 어디에 있든 쓰다듬을 수 있어요: 밥그릇·물그릇·화장실 앞에서는 하던 일을 계속하며 손을 받아 주고, 삐져서 구석에 가 있을 땐 처음엔 어깨를 털어 내지만 살살 계속 쓰다듬으면 마음이 풀려 돌아앉아요(아직 낯선 고양이는 반대편 구석으로 가 버려요) |
| 부르기 / 관심 끌기 | 빈 곳을 톡 두드리기, 두 번 두드리면 노크 |
| 확대 / 축소 | 두 손가락을 벌리거나 오므리기 (두 손가락 사이를 중심으로 가까이·멀리 봐요. 두 손가락을 함께 움직이면 화면이 따라가고, 가까이 본 채로는 한 손가락으로 위아래·옆 어디로든 둘러볼 수 있어요. 끝까지 멀리 보면 창 위 선반과 벽시계, 액자까지 방 전체가 한눈에 들어와요. 데스크톱에선 마우스 휠이나 트랙패드 핀치. 고양이를 쓰다듬던 두 손가락을 벌려도 확대가 돼요) |
| 방 둘러보기 | 빈 곳에 손가락을 대고 옆으로 밀기 (방이 손가락을 따라 움직이고, 놓으면 미끄러지듯 멈춰요. 왼쪽 끝엔 스크래쳐와 그림·시계, 오른쪽 끝엔 몬스테라와 책 선반, 화장실이 있어요. 빠르게 좌우로 문지르면 둘러보기 대신 사료를 부어요. 고양이를 쓰다듬거나 장난감을 집거나 25초 동안 아무것도 안 하면 다시 고양이를 따라가요. 방 전체가 한 화면에 들어오는 가로 화면·태블릿에선 움직이지 않아요. 고양이는 절대 방 밖으로 나가지 않아서, 둘러보면 언제나 어딘가에 있어요. 당신을 좋아하고 한가한 고양이는 가끔 당신이 보는 쪽으로 어슬렁 따라와 킁킁 냄새를 맡고는, 그 앞에 비스듬히 앉아 당신을 올려다봐요) |
| 코 톡 (부프) | 당신을 믿는 고양이의 코를 손가락으로 한 번 톡 (눈을 질끈 감았다가 코를 핥고 도리도리, 가끔 '끄릉'. 연달아 콕콕 찌르면 귀찮아해요) |
| 같이 놀기 | 털실 공을 손가락으로 잡고 바닥 위로 끌기 (톡 치면 굴러가요) |
| 손가락으로 놀기 | 고양이 앞 빈 곳에 손가락을 대고 천천히 움직이기 (놀고 싶은 고양이는 앞으로 와서 손가락을 노려보다 앞발로 손끝을 톡 쳐요. 손가락이 높으면 뒷발로 일어서서 두 앞발을 뻗어요) |
| 레이저 포인터 | 창턱의 레이저 포인터를 톡 눌러 들고, 화면을 누른 채 움직이기 (빨간 점은 손끝 조금 위에 떠요. 화면 아래 손에 든 포인터를 톡 누르면 내려놓아요. 고양이는 방 양 끝 구석까지 쫓아가요. 가까이 있는 점은 몸을 돌려 조준한 다음 엉덩이를 씰룩이다 거리만큼 도약해 앞발로 덮치고, 놓치면 잠깐 웅크려 어디 갔나 살핀 뒤 다시 쫓아요. 멀어지면 몸을 일으키며 바로 달려 나가고, 화분·스탠드·책 더미·스크래쳐 같은 물건은 돌아서 지나가요(어떤 물건도 통과하지 않아요). 손가락을 화면 맨 가장자리에 잠깐 대고 있으면 방이 그쪽으로 천천히 따라가고, 두 손가락으로는 포인터를 든 채 확대·축소하거나 화면을 옮길 수 있어요) |
| 스크래쳐 방울 | 방 왼쪽 끝 스크래쳐에 매달린 분홍 방울을 손가락으로 잡아 끌었다 놓거나 톡 치기 (방울이 흔들리면 고양이가 쳐다보고, 놀 기분이면 달려와 앉아서 앞발로 탁탁 쳐요) |
| 깃털 낚싯대 | 바닥의 낚싯대(깃털이나 막대)를 잡고 흔들기. 아래로 내리면 깃털이 바닥을 기고, 위로 들면 공중에서 흔들려요. 손을 떼면 그 자리에 떨어져요 |
| 장난감 쥐 던지기 | 바닥의 회색 펠트 쥐를 톡 누르기 (방 안쪽으로 던져져요. 고양이가 쫓아가 물어 오기도 해요) |
| 스탠드 끄고 켜기 | 스탠드 갓을 톡 누르기 (딸깍. 밤에 끄면 꼬마전구와 달빛만 남은 푸른 방이 되고, 어둠 속 고양이 눈이 은은하게 빛나요. 깨어 있던 고양이는 가끔 불이 꺼지자마자 우다다를 해요. 자는데 불을 다시 켜면 귀를 털며 한쪽 눈을 가늘게 떴다가, 웅크려 자던 중이면 앞발을 들어 눈을 가리고 한참 그대로 자요. 다음에 시간대가 바뀌면 다시 저절로 돌아가요) |
| 깨진 컵 치우기 | 바닥의 찻잔 조각을 톡 누르기 (조금 지나면 창턱에 새 차가 놓여요) |
| 사료 주기 | 휴대폰 흔들기 (사료 봉지 소리), 또는 빈 곳을 좌우로 빠르게 문지르기 (배고픈 고양이는 그 소리에 귀를 쫑긋하고 바로 일어나, 배고플수록 서둘러 종종걸음으로 밥그릇에 가요. 밥그릇 앞에선 먼저 킁킁 냄새를 맡고, 몇 입 먹고는 고개를 들어 오물오물 씹으며 둘레를 한 번 보고 다시 먹어요. 물을 마실 땐 잠깐씩 멈춰 입술을 핥아요) |
| 물 주기 | 빈 곳을 길게 누르고 있기 (누르는 동안 물이 따라져요) |
| 화장실 모래 치우기 | 빈 곳을 아래로 쓸어내리기 |
| 작별 인사 / 새 고양이 | 숨을 멈춘 고양이를 오래 누르기 → 빈 창가를 오래 누르기 |
| 음악 끄기 / 켜기 | 창턱의 라디오를 톡 누르기 (상태를 기억해요) |
| 크레딧 보기 | 창턱의 작은 그림 액자를 톡 누르기 |
| 고개 옮겨 보기 | 휴대폰을 살짝 기울이기 (고개를 옆으로 옮긴 것처럼 방과 창밖 풍경이 깊이에 따라 다르게 움직여요. 멀수록 많이) |

필요한 순간에만 화면 아래에 옅은 안내 문장이 잠깐 나타납니다. 데스크톱에서는 `F`(사료), `W`(누르고 있으면 물), `L`(모래)도 됩니다.

## 고양이의 마음

- **부위별 호불호**: 턱·볼·머리·목덜미는 좋아하고, 꼬리·발·배는 싫어해요. 고양이마다 성격(좋아하는 부위, 참을성, 목소리)이 조금씩 다릅니다.
- **결과 속도**: 털 결을 거스르거나 너무 빠르게 문지르면 싫어하고, 거슬러 쓴 털은 한동안 헝클어진 채 남아요. 다만 쓸어 주는 게 아니라 손끝으로 한 자리를 박박 긁어 주는 건(앞뒤로든 동그랗게든) 결도 빠르기도 따지지 않아요: 정수리, 귀 뿌리, 볼, 턱 밑, 꼬리 뿌리는 쓰다듬기보다 긁어 주는 걸 더 좋아해요(낯선 사람이 긁는 건 빼고요). 눈이나 코를 문지르는 건 긁든 쓸든 싫어해요. 믿는 손이 꼬리 뿌리를 한참 긁어 주면 엉덩이를 치켜들고, 가끔은 코를 쳐들고 허공을 날름날름 핥아요(고양이들이 어쩔 수 없이 하는 반응이에요. 손가락엔 닿지 않으니 손끝에 느껴지진 않아요). 좋으면서도 싫은 손엔 마음이 반반이라도 '좋아'와 '싫어'를 순간순간 오가지 않아요: 기분 좋던 고양이는 꽤 싫어질 때까지 참고, 한번 짜증 난 고양이는 웬만큼 풀려야 다시 좋아해요.
- **과자극**: 좋아하는 곳도 너무 오래 만지면 꼬리 끝이 까딱이고, 등 가죽이 꿈틀거리고, 귀가 젖혀지고, 입을 거의 다문 채 낮게 '으응…' 하고 투덜거리다(경고예요), 결국 하악질과 솜방망이, 그래도 계속하면 도망갑니다.
- **기분이 좋으면** 골골송(소리 + 지원 기기에서는 진동), 눈을 지그시 감기, 손에 머리를 기대기, 꾹꾹이, 천천히 눈 깜빡이기(고양이식 애정 표현).
- **손가락 핥기**: 당신을 깊이 믿는 고양이를 기분 좋게 쓰다듬다가 머리(볼, 턱 밑)에 손가락을 가만히 대고 있으면, 가끔 고개를 들어 그 손가락을 까끌까끌한 혀로 서너 번 핥아 줘요(눈을 반쯤 감고). 핥을 때마다 손끝에 작게 사각하고 느껴지고(진동이 되는 기기에서) 아주 작게 소리가 나요. 다 핥고 나면 가끔 혀끝을 쏙 내민 채 잊어버리고 있어요(블렙). 세수나 그루밍, 코 톡 뒤에도 가끔 그렇고, 어떤 날은 혀끝을 내민 채로 깊이 잠들어요.
- **배는 함정**: 고양이가 배를 보여 줄 때(반가워서 발라당 누웠을 때, 햇살에서 뒹굴거나 옆으로 쭉 뻗어 누웠을 때, 배를 드러내고 잘 때) 배를 만지면, 순식간에 앞발로 손가락을 와락 끌어안고 고개를 숙여 깨물면서 뒷발로 팡팡 차요(토끼차기). 차는 발마다 손끝에 톡톡 느껴지고, 깨물 땐 조금 더 세게 느껴져요. 손가락을 떼면 바로 놓아주고는, 아무 일 없었다는 듯 눈을 동그랗게 뜨고 당신을 봐요. 반은 장난, 반은 진심이에요: 함정에 걸린 동안은 괜찮지만, 그 뒤에도 손을 배에 계속 두면 평소처럼 싫어해요. 배를 보여 주는 건 그만큼 당신을 믿는다는 뜻이지, 만져 달라는 뜻은 아니거든요.
- **손에 눌리는 귀**: 정수리나 두 귀 사이를 쓰다듬으면 귀가 손가락에 눌려 뒤로 납작하게 접히고, 손을 떼면 귀를 살짝 털며 퐁 하고 다시 서요(자고 있어도, 좋든 싫든 귀는 원래 눌려요).
- **쓰다듬은 뒤**: 한참 쓰다듬다 손을 떼면, 고양이는 자주 만져진 곳의 털을 정리해요. 머리를 만졌으면 앞발을 핥아 얼굴을 닦고, 등·옆구리면 고개를 돌려 그 자리를 핥고, 가슴이면 턱을 당겨 가슴 털을 핥아요. 털을 거슬러 쓸었다면 거의 꼭 그래요.
- **쓰다듬는 동안의 화면**: 화면이 고양이에게 다가간 뒤에는 고양이가 꿈틀거리거나 발을 차도 화면이 같이 흔들리지 않아요(손을 대고 있는 동안 고양이가 몸을 낮추면 손이 따라가듯 천천히 따라가고, 손을 떼고 있으면 가만히 있어요). 고개를 살짝 돌리는 정도로는 화면이 들락날락하지 않아요. 동그랗게 말아 자던 고양이를 깨우면 일어나 빙 돌지 않고 말린 채로 눈을 뜨고 당신을 봐요(손이 떠나고 한참 뒤에야 제대로 일어나 돌아누워요). 등 뒤에서 쓰다듬어도 고개를 이쪽 어깨에서 저쪽 어깨로 홱 돌리지 않고, 손이 얹혀 있는 동안엔 딴 데를 힐끔거리지도 않아요. 손끝이 털 가장자리에 살짝 걸쳐도 쓰다듬기로 쳐요(다가간 화면에선 더 넉넉하게. 다만 장난감 위에선 장난감이 먼저). 쓰다듬다 빗나간 손가락에 고양이가 일어나 손끝을 톡톡 치러 오지도 않아요.
- **신뢰도**는 모든 접촉으로 조금씩 변해요. 낮으면 잘 놀라고 경계하며 하악질이 빨라지고, 높으면 먼저 다가와 트릴로 인사하고 알림으로 당신을 부릅니다.
- **쉴 때**: 침대에서 깨어 쉴 땐 정면이 아니라 옆으로 비스듬히 엎드리거나 앉아요(들어온 방향 쪽으로). 등선과 꼬리가 보이고, 고개만 돌려 당신을 봐요. 그렇다고 당신만 빤히 보지는 않아요(고양이는 누구든 오래 쳐다보지 않거든요): 한동안 당신을 보다가, 한동안은 눈을 반쯤 감고 제 앞쪽 어딘가를 멍하니 보고, 가끔 옆쪽 방 안을 슬쩍 둘러봐요. 당신을 믿을수록, 방금 만지거나 놀아 줬을수록 당신을 더 자주 보고, 손을 대고 있을 때와 천천히 눈을 깜빡여 줄 땐 늘 당신을 봐요.
- **잠**: 대부분 자고, 가끔 한쪽 눈만 살짝 떠서(옆으로 누워 있으면 위쪽 눈) 당신을 확인하고, 한숨을 쉬고, 귀를 움찔해요. 졸릴 때는 엎드린 채 고개가 스르르 떨어지다 흠칫 들기를 몇 번 하다가 잠들어요(꾸벅꾸벅). 타고나길 코를 고는 고양이(셋에 하나쯤)는 깊이 잠든 동안 가끔 한동안, 숨을 들이쉴 때마다 아주 작게 코를 골아요. 깊이 잠들면 꿈을 꾸듯 발을 움찔거리고(가끔은 들릴 듯 말 듯 잠꼬대처럼 작게 냥 해요. 어떤 꿈에선 네 발을 다 허우적대며 몇 초간 자면서 달리기도 해요), 몇 분에 한 번쯤은 자면서 다리를 쭉 뻗고 고개를 젖히며 입을 살짝 벌렸다가 다시 웅크려요. 자는 동안 창밖 새소리 같은 소리가 나면 눈은 감은 채 그쪽 귀만 레이더처럼 돌려 듣다가 잠시 뒤 제자리로 돌아와요. 옆으로 길게 누워 있다가 짜증이 나면(너무 만졌을 때처럼) 꼬리를 바닥에서 들었다가 탁 내리치기를 되풀이해요(짜증이 클수록 자주, 작게 툭 소리도 나요). 햇살 드는 낮에 웅크려 자다 보면 위쪽 앞발을 머리 위로 넘겨 눈을 가리고 한참 그대로 자요(해가 지거나 깨면 내려놓아요). 한 번에 몇십 분씩 낮잠을 자고 나면 스스로 깨어나요. 누운 채로 작게 끽 소리를 내며 크게 하품하고, 일어나 옆으로 돌아서서 기지개를 쭉 켠 다음(앞다리, 그리고 뒷다리 하나씩) 당신 쪽으로 돌아 다시 엎드려요. 잠들 때마다 오른쪽이나 왼쪽으로 코와 꼬리가 맞닿게 동그랗게 몸을 말고(꼬리를 앞으로 둘러 코끝까지 감고, 잠든 얼굴이 당신 쪽으로 보이게), 자는 동안 옆구리가 숨에 맞춰 천천히 오르내려요. 당신을 아주 믿는 고양이는 가끔 깊이 잠들면서 데굴 굴러 배를 하늘로 드러내고 자요: 앞발은 가슴 위에 오므리고 뒷발은 벌린 채 분홍 젤리를 보이고, 머리는 침대 턱에 걸쳐 거꾸로 당신 쪽을 향해요. 믿는 고양이를 아주 오래(1분 넘게) 쓰다듬고 있으면, 슬슬 됐다는 듯 고개를 손가락 쪽으로 돌려 살짝 '앙' 물었다가(손끝에 톡 하고 느껴져요) 놓고는 그 자리를 두어 번 핥아 줘요. 화가 난 게 아니라 '이제 충분해, 고마워' 하는 애정 표현(러브 바이트)이에요. 당신을 아주 믿는 고양이는 자는 동안 등이나 머리를 쓰다듬어도 깨지 않아요: 귀만 살짝 돌리고 한쪽 눈을 가늘게 떴다 감고는, 웅크린 그대로 얕게 자면서 골골송을 불러요(꼬리·발·배는 자면서도 싫어하고, 톡 치면 깨요. 아직 낯을 가리는 고양이는 화들짝 깨요). 새벽과 해질녘에 더 활발합니다.
- **다시 왔을 때**: 한동안 자리를 비웠다가 앱을 다시 열면 고양이가 알아봐요. 당신을 좋아하고 오래 비웠을수록 더 반가워해요: 깨어 있으면 귀를 쫑긋 세우고 트릴을 하고는(다섯 시간 넘게 비웠다 오면 다가오는 내내 야옹, 트릴, 짹 하며 그동안 있었던 일을 한참 얘기해요. 수다스러운 고양이일수록 더), 꼬리를 물음표처럼 곧게 세운 채(고양이식 '안녕'. 아주 반가우면 세운 꼬리가 파르르 떨려요) 당신 바로 앞까지 걸어와 살짝 비스듬히 앉아 고개를 돌려 당신을 올려다보며 천천히 눈을 깜빡여요. 많이 좋아하면 당신 쪽으로 머리를 콩 밀고 고개를 기울여 볼을 비빈 다음, 한동안 그 자리에서 당신을 바라보다 제 할 일로 돌아가요. 장난감 쥐를 물어다 주며 맞이하는 날도 있고, 정말 반가운 날엔 가끔 당신 앞에 발라당 옆으로 누워 배를 보이고는, 등을 바닥에 비비적거리며 거꾸로 당신을 올려다봐요(고양이가 할 수 있는 가장 따뜻한 환영이에요). 당신을 많이 그리워한 고양이는 한 시간 넘게 비웠다 돌아오면 가끔 이미 당신 바로 앞에 앉아 고개를 떨군 채 기다리고 있다가, 당신이 나타나는 순간 고개를 번쩍 들고 귀를 쫑긋, 눈을 동그랗게 뜨고 트릴로 반겨요. 자고 있었다면 곧 한쪽 눈을 떠서 당신을 확인하고, 믿는 사이면 천천히 눈을 깜빡이고는 다시 자요(정이 든 고양이는 오래 비웠다 돌아오면 낮잠에서 깨어 반기러 오기도 해요). 아직 낯을 가리는 고양이는 눈만 떠 보고 말아요.
- **갸웃**: 빈 곳을 톡 두드리거나 어디서 나는지 모를 소리가 나면, 귀를 쫑긋 세우고 고개를 한쪽으로 갸웃해요.
- **당신 곁에서 낮잠**: 당신을 아주 믿는 고양이는 졸릴 때 가끔 침대 대신 당신과 가장 가까운 곳에 와서 당신 쪽을 보고 식빵을 굽거나 옆으로 길게 누워(발바닥 젤리가 보이게) 그대로 꾸벅꾸벅 잠들어요. 곁에 누워 있는 동안엔 만지지 않아도 작게 골골거려요(당신 곁이 좋대요). 깨면 잠시 그대로 있다가, 졸리면 침대로 돌아가고 아니면 거기서 좀 더 머물러요.
- **손가락 사냥**: 고양이 앞 빈 곳에 손가락을 대고 천천히 움직이면 고양이 눈이 손가락을 따라가요. 놀고 싶거나 당신을 믿는 고양이는 손가락 아래로 와서 앉아 귀를 세우고 눈을 동그랗게 뜬 채 손가락을 노려보다가(처음엔 종종 고개를 쭉 내밀어 손가락 냄새를 킁킁 맡아요), 앞발을 뻗어 손끝을 톡 쳐요. 손목을 젖혀 분홍 발바닥(젤리)이 손끝에 납작하게 닿고, 가끔은 톡톡 두 번. 손가락이 조금 높으면 엉덩이를 붙인 채 몸을 세워서, 더 높으면 뒷발로 일어서서 두 앞발로 한 발씩 번갈아 톡톡 쳐요. 발이 닿을 때마다 손끝에 톡 하고 느껴지고(진동이 되는 기기에서) 작게 톡 소리가 나요. 손가락이 손 닿지 않는 데로 미끄러져 가면 따라가고, 손가락을 떼면 어디 갔나 잠깐 두리번거려요. 손가락을 가만히 대고만 있으면 한두 번 톡 쳐 보고는 시시해해요. 다만 당신을 많이 믿고 사랑하는 고양이라면, 고개 높이쯤에 손가락을 가만히 대고 있을 때 놀이 대신 그 앞으로 엉덩이를 끌며 다가와 눈을 감고 손가락에 볼을 비벼요(가끔 '끄릉'). 두세 번 볼을 문지를 때마다 손끝에 살짝 느껴지고, 다 비비고 나면 물러앉아 당신을 보며 천천히 눈을 깜빡여요. 실컷 놀고 나면 가끔 아무 일 없었다는 듯 그 앞발을 핥아요. 거꾸로, 놀고 싶은데 아무도 놀아 주지 않으면 가끔은 고양이가 먼저 당신 앞으로 와서 앉아 당신을 보며 짧게 '끄릉' 하고는, 앞발로 톡 치거나 뒷발로 일어서서 앞발을 뻗으며 놀자고 해요(그때 손가락을 대면 놀이가 시작돼요).
- **더 해 줘**: 한창 좋아하며 쓰다듬기를 받던 고양이는 아직 충분하지 않은데 손이 떠나면, 손이 있던 쪽으로 머리를 쭉 내밀어 허공에 볼을 두어 번 비비고(등을 쓰다듬던 중이면 엉덩이를 들어 올리고), 귀를 세우고 눈을 동그랗게 떠 당신을 보며 '끄릉?' 하고 물어요. 곧 다시 쓰다듬어 주면 골골송이 바로 커지고 천천히 눈을 깜빡여요. 이미 실컷 받았거나(살짝 깨물었으면 그 뜻이에요) 졸릴 땐 조르지 않아요.
- **수염**: 픽셀아트에서도 양쪽 세 가닥씩 수염이 보여요(호기심이 나면 앞으로, 겁이 나면 뒤로 젖혀지고, 잘 때는 뺨에 붙어 안 보여요).
- **계절을 타요**: 방 안의 더위와 추위는 실제 날짜와 시간을 따라가요(1월 말이 가장 춥고, 7월 말~8월 초 오후가 가장 더워요. 10월 말부터 4월 초까지는 난방이 들어와요). 추운 날엔 거의 늘 동그랗게 몸을 말아 자고, 깨어 쉴 때도 앞발을 몸 밑에 넣은 식빵 자세를 즐기며, 햇살 자리와 라디에이터 옆을 더 자주 찾아요. 더운 여름 오후엔 옆으로 쭉 뻗어 자거나(당신을 믿으면 가끔 배를 드러내고 벌러덩), 햇볕을 피해 침대 앞 맨바닥에 길게 드러누워 한참 더위를 식혀요.
- **공기 냄새**: 깨어 쉬다가 가끔 고개를 살짝 들고 코를 킁킁, 수염을 앞으로 모으고 귀를 세워요. 공기 중에 뭔가 냄새가 나나 봐요(호기심 많은 고양이일수록 자주).
- **겁먹은 몸**: 겁이 나면서 화도 난 채 서 있을 땐 다리를 꼿꼿이 펴고 등을 아치처럼 둥글게 솟구쳐 몸을 크게 보이게 하고, 그냥 겁만 난 채 서 있거나 걸을 땐 다리를 굽혀 몸을 낮게 깔고, 고개를 숙여 앞으로 내밀고, 귀를 옆으로 눕히고 꼬리를 내린 채 살금살금 움직여요. 겁이 가라앉는 만큼 천천히 몸이 다시 올라와요. 놀란 일이 지나가고 겁이 다 가라앉으면, 아무 일 없었다는 듯 어깨나 가슴을 몇 번 핥으며 스스로를 진정시키기도 해요(늘 그러진 않고, 하던 일이 있으면 끝낸 뒤에). 크게 놀란 뒤 몇 분 동안은 겁은 가셔도 긴장이 덜 풀려 있어요: 눈이 동그랗고 동공이 조금 크고, 귀를 자꾸 이리저리 돌리고, 꼬리를 조금 낮게 들고 몸을 살짝 낮춰 다녀요. 그동안은 놀이를 잘 안 하고, 상자에 들어가거나 당신 곁에 있거나, 가만히 두리번거리며 공기 냄새를 맡아요. 그러다 또 천둥이 치거나 못 본 손이 닿으면 더 크게 놀라요. 기분 좋게 쓰다듬어 주거나 한숨 자고 나면 금방 풀려요.
- **눈**: 그림 위에 실시간으로 그려지는 눈이 당신(화면)을 보거나 손가락을 따라가요. 동공은 빛·흥분·공포에 따라 커지고 줄어들고, 눈동자에는 이 창(화면)이 비쳐요. 무언가로 눈길을 옮길 땐 눈이 먼저 휙 건너가고 머리가 뒤따라 부드럽게 돌아가요(실제 고양이처럼). 눈을 감으면(깜빡일 때, 졸 때, 골골거리며 지그시 감을 때) 눈꺼풀은 주변과 같은 털빛이고 속눈썹 선만 보여요.
- **고양이의 눈으로 본 방 (작은 신경계)**: 고양이는 방을 다 아는 게 아니라, 제 눈이 있는 자리에서 보이는 것만 봐요. 시야는 양옆으로 넓지만(약 200°) 등 뒤는 못 보고, 가운데는 또렷하지만 가장자리에선 움직이는 것만 눈에 띄며, 화분·상자·책 더미·스크래쳐 뒤에 숨은 건 보이지 않아요. 보이는 것도 눈과 뇌가 처리하는 동안 10분의 1초쯤 늦게 보이고, 너무 빨리 휙 지나가는 건 줄무늬처럼 번져서 '뭔가 지나갔다'는 것만 알지 어디인지는 몰라요. 그렇게 본 것마다 작은 신경망의 뉴런이 하나씩 반응해요: 먹잇감처럼 움직이는 것, 막 나타난 것, 아는 얼굴일수록 세게. 뉴런들은 서로를 억누르고(한 번에 하나만 눈여겨봐요) 제 자신은 북돋우며(한 번 눈길이 가면 잠시 머물러요), 같은 자극이 그대로 계속되면 점점 둔해져서(가만히 있는 장난감은 곧 시시해져요) 다시 움직이면 되살아나요. 가장 세게 반응하는 것을 바라보고, 그게 있다고 믿는 곳을 쫓아가요(안 보이게 되면 가던 쪽으로 조금 이어서 짐작하다가 점점 자신이 없어져요). 먹잇감에 눈길이 오래 갈수록 사냥 욕구가 천천히 차오르고, 사라지면 천천히 가라앉아요. 그래서 레이저 점을 등 뒤에서 비추면 바로는 몰라요(포인터를 켜는 '딸깍'에 두리번거리며 몸을 돌려 찾고), 점을 너무 빨리 휘두르면 놓치고 두리번거리다 점이 멈추면 다시 발견해 덮쳐요. 깃털 낚싯대와 털실도 마찬가지예요: 고양이는 제 눈에 보인 자리를 보고, 쫓고, 앞발을 뻗어요(앞발이 닿는지는 실제 자리로 정해져서, 그새 휙 움직였으면 헛손질해요). 그래서 빨리 흔들어도 고개가 홱홱 꺾이지 않아요.
- **당신의 시간을 익혀요**: 고양이는 당신이 언제 놀아 주는지(레이저, 깃털 낚싯대, 털실)와 언제 쓰다듬어 주는지를 시간대별로 기억해요. 며칠 저녁 여덟 시쯤 레이저로 놀아 줬다면, 그 시간이 다가오면 창턱의 레이저 포인터 쪽을 자꾸 쳐다보고, 놀자고 앞에 와서 조르거나 포인터 근처에 가서 당신을 보며 기다려요(작게 야옹 하기도 해요). 포인터를 집으면 더 빨리 달려들어요. 늘 쓰다듬어 주던 시간엔 당신 가까이 와서 기다리고요. 밥 주는 시간도 기억해서, 며칠 같은 시간에 사료를 줬다면 그 무렵 밥그릇이 비어 있으면 아직 많이 배고프지 않아도 미리 밥그릇 옆에 가서 앉아 당신을 보며 기다려요. 한동안 그 시간에 놀아 주지 않으면 습관은 몇 주에 걸쳐 천천히 잊혀요.
- **외면당하면**: 놀자고 와서 조르다 아무도 대답하지 않으면, 가끔 고개를 툭 떨구고 작게 한숨을 쉬고는 제 할 일로 돌아가요(그런 일이 잦으면 조르는 일도 차츰 줄어요).
- **상자 매복**: 고양이가 상자에 들어가 앉아 있을 때 깃털 낚싯대를 흔들거나 레이저 점을 비추거나 털실을 굴리면, 느릿느릿 돌아서 나오는 대신 상자 안으로 몸을 푹 낮추고 가장자리 너머로 눈만 내놓은 채(동공이 커지고 수염이 앞으로) 노려봐요. 엉덩이를 살짝 씰룩이다가 그쪽으로 상자 벽을 넘어 휙 튀어나가 바로 놀이를 시작해요. 너무 졸릴 땐 그냥 천천히 나와요.
- **자다가 뒤척이기**: 깊이 오래 자는 동안 10~20분에 한 번쯤 반쯤 깨서 자세를 바꿔요. 몸을 조금 일으켜 돌아눕거나(반대쪽으로 동그랗게), 일어나 한 바퀴 돌고 옆으로 길게 눕거나, 당신을 아주 믿으면 배를 드러내고 벌러덩 누워요. 다시 자리를 잡으면 한숨을 쉬어요. 기지개를 켜는 중이거나 햇살에 앞발로 눈을 가리고 있을 땐 뒤척이지 않아요.
- **그루밍하다 멈칫**: 털을 고르거나 세수하거나 뒷발로 귀를 긁는 중에 뭔가 움직이거나 새로 나타나면(굴러가는 털실, 날아든 벌레, 레이저 포인터의 딸깍), 하던 자세 그대로 멈추고 고개를 들어 그쪽을 잠깐 봐요. 핥다가 멈추면 혀끝이 살짝 나와 있기도 하고, 귀를 긁다 멈추면 뒷발을 든 채로 굳어요. 별일 아니면 하던 데부터 다시 이어 가요.
- **해 보고 배워요**: 고양이는 제 마음대로 한 일 뒤에 무슨 일이 생겼는지 기억해요. 당신 앞으로 왔을 때 쓰다듬어 주거나, 놀자고 조를 때 레이저·깃털·털실로 놀아 주거나, 물어 온 쥐 인형을 던져 주면, 그 직전에 한 일을 점점 더 자주 해요(방금 한 일일수록 더 많이 배워요). 창턱에서 찻잔을 밀다가 혼나거나, 다가갔다가 거칠게 만져져 짜증이 나면 그 일은 덜 하게 되고요. 당신을 위해 한 일(앞으로 오기, 조르기, 선물, 곁에서 낮잠)에 1분이 지나도록 아무 반응이 없으면 조금씩 덜 해요(당신이 한참 아무것도 안 하고 있을 땐 따지지 않아요). 배운 건 두어 주에 걸쳐 천천히 흐려지고, 아무리 배워도 몇 배 이상 치우치진 않아요. 그래서 키우는 사람마다 고양이가 조금씩 다르게 자라요. 마음 창에서 '배운 것'으로 볼 수 있어요.
- **저마다의 목소리**: 고양이마다 목소리 높이가 달라요. 새 고양이가 올 때 정해져서(대개는 중간, 가끔 가늘고 높은 목소리나 낮은 목소리) 야옹, 트릴, 짹짹, 하악, 하품 소리, 골골송까지 그 고양이의 목소리로 나고, 같은 소리도 할 때마다 조금씩 달라요.
- **저마다의 기질**: 고양이마다 타고난 기질이 조금씩 달라요. 대담한지 소심한지, 장난을 좋아하는지 점잖은지, 게으른지 부지런한지, 호기심이 많은지가 새 고양이가 올 때 정해지고(대부분은 중간쯤이고 가끔 한쪽으로 치우친 고양이가 와요), 그 뒤로 내내 그대로예요. 장난꾸러기는 놀이를 더 자주 하고, 게으른 고양이는 햇살 자리에 오래 눕고 느릿느릿 일어나요. 대담한 고양이는 창턱이나 스크래쳐 꼭대기, 상자를 더 즐기고 천둥이나 못 본 손에도 덜 놀라요. 호기심 많은 고양이는 눈길이 이리저리 자주 가고, 눈에 띈 것에 더 쉽게 끌려가요.
- **바뀐 걸 알아채요**: 고양이는 제 물건(털실, 쥐 인형, 깃털)이 어디 있었는지 기억해요. 자거나 딴 데를 보는 사이에 당신이 옮겨 두면, 다음에 그걸 봤을 때 '어, 저게 왜 저기 있지' 하고 눈길이 가고(하던 걸 마치면) 다가가서 목을 쭉 빼고 킁킁 냄새를 맡아 봐요. 눈앞에서 옮기는 걸 봤다면 어디로 갔는지 아니까 놀라지 않아요.
- **못 본 손에 깜짝**: 깨어 있는 고양이를 만질 때, 손이 다가오는 걸 봤다면(당신 쪽을 보고 있었으면 등을 만져도) 그냥 받아들이지만, 고개를 돌리고 있어 못 본 손이 갑자기 닿으면 움찔 놀라 귀를 털고 그쪽을 돌아봐요(당신을 믿을수록 덜 놀라요).
- **집사 확인하기**: 천둥이 치거나 찻잔이 깨지거나 못 본 손에 놀라면, 잠깐 뒤 당신 쪽을 슬쩍 쳐다봐요('방금 그거 뭐야?' 하듯이). 당신을 믿을수록 더 자주 그래요.
- **귀로 듣기**: 귀는 눈길을 따라가기도 하지만, 보고 있지 않은 소리에도 돌아가요. 라디오에서 음악이 나오면 가끔 그쪽 귀가 라디오를 향해 홱 돌아갔다가 돌아오고, 비가 세게 오면 창 쪽으로 귀를 기울여요(뒤에서 나는 소리엔 귀를 뒤로 완전히 돌려요).
- **숨이 차요**: 한바탕 뛰고 나면(레이저 쫓기, 우다다) 그만큼 숨이 가빠져서 옆구리가 더 빠르고 깊게 오르내리고, 30초쯤에 걸쳐 천천히 가라앉아요. 아주 오래 전력으로 뛰고 나서 멈추면 잠깐 입을 살짝 벌리고 혀끝을 내민 채 헐떡이기도 해요.
- **가까이 들여다보기**: 두 손가락으로 고양이 얼굴을 화면 가득 확대하면, 고양이에겐 당신 얼굴이 코앞에 다가온 거예요. 깨어 있다면 곧 당신 쪽을 봐요. 당신을 믿는 고양이는 수염을 앞으로 내밀고 귀를 세운 채 코를 킁킁거리며 냄새를 맡고(처음엔 열심히, 당신인 걸 알고 나면 점점 덜), 당신을 많이 믿으면 곧 천천히 눈을 깜빡여 주고 가끔 작게 트릴도 해요. 그동안은 딴 데 갈 생각을 잠시 잊어요. 아직 낯선 고양이는 귀를 뒤로 젖히고 고개를 살짝 뒤로 빼며 눈이 동그래졌다가, 잠깐 뒤 눈을 깜빡이며 시선을 옆으로 피해요(고양이끼리 빤히 쳐다보는 건 실례라서요). 그래도 계속 가까이 있으면 돌아앉아 등을 보여요. 당신을 아주 좋아하는 고양이는 가끔, 눈을 깜빡여 준 뒤 눈을 꼭 감고 이마를 당신 얼굴에 콩 들이밀고는 볼을 쓱 비비며 지나가요(손끝에 콩 하고 느껴지고 화면도 살짝 밀려요. 한 번 하고 나면 한동안은 안 해요). 손으로 쓰다듬을 때 화면이 다가가는 건 손 때문이라 이 반응은 나오지 않아요.
- **고양이의 마음 들여다보기**: 두 손가락으로 화면을 두 번 톡톡 치거나 세 손가락으로 한꺼번에 누르면(아이폰에선 세 손가락이 '실행 취소' 메뉴를 띄우니 두 손가락으로, 컴퓨터에선 M 키, 주소 끝에 ?mind) 오른쪽 위에 작은 창이 열려요. 고양이 눈 위치에서 고양이가 바라보는 쪽을 넓게 그린 방이 보이고(고양이처럼 파랑과 노랑 위주의 흐린 색으로, 가장자리는 어둡게), 고양이의 신경망이 반응하는 것마다 표시가 찍혀요(세게 반응할수록 크게, 지금 주목하는 것엔 노란 테두리). 아래엔 지금 기분(들뜸·느긋함·나른함·차분함: 얼마나 자주 뭔가를 하고 싶어지는지), 지금 보는 것, 사냥 욕구, 하려는 것, 궁금한 것, 이 시간에 기다리는 것, 그리고 아무것도 안 할 땐 가장 끌리는 욕구 두 개가 비율로 적혀요(눈길이 가 있는 것에 대한 욕구는 그만큼 커져요). 같은 동작으로 다시 닫아요. 졸리면 창에 눈꺼풀이 내려오고, 잠들면 깜깜해지며, 깊이 잠들어 발을 움찔거릴 땐 무슨 꿈을 꾸는지(요즘 가장 오래 눈여겨본 것) 적혀요.
- **보고 나서 움직이기 (욕구와 의도)**: 혼자 있을 때 무엇을 할지는 몇 초마다 주사위를 던져 정하지 않아요. 그루밍, 털실 놀이, 상자, 창턱, 스크래쳐 같은 할 일마다 기분에 따라 세기가 다른 욕구가 있고, 그 대상에 눈길이 가 있는 동안에는 그 욕구가 몇 배로 커져요(지나가다 눈에 들어온 털실이 갑자기 갖고 싶어지듯이요). 욕구가 하나 떠오르면 바로 움직이지 않고 먼저 그쪽을 바라봐요: 눈이 가고, 고개와 귀가 따라가고, 잠깐 머문 뒤에야 일어나서 가요. 그사이 다른 것이 눈길을 빼앗으면 하려던 걸 잊어버리고, 등 뒤처럼 안 보이는 곳이면 어디 있는지 알기에 그냥 돌아서 가요. 한 가지를 마치면 한동안은 그냥 쉬어요. 얼마나 자주 뭔가를 하는지도 기분 따라 달라요: 신나 있으면 이것저것 하지만, 차분하거나 졸릴 땐 대부분 그냥 앉거나 엎드려 방을 둘러보고 귀를 쫑긋거리다 가끔 하나씩 해요(몇 분 들썩였다가 한동안 잠잠해지는 식으로 기복도 있어요). 고양이답게 새벽과 해질녘엔 더 부지런하고 더 오래 깨어 있어요. 아무도 만지지 않으면 깨어 있는 동안 이렇게 몇 분에서 십여 분쯤 지내다가 꾸벅꾸벅 졸고 낮잠에 들어요. 그리고 뭔가를 할 때마다 침대로 꼬박꼬박 돌아가지도 않아요: 졸리거나 밤이면 돌아가지만, 아니면 그 자리에 앉거나 엎드려(옆으로 길게 눕는 건 자리가 넉넉할 때만) 있다가 근처의 다른 걸 하거나, 자기 때가 되면 돌아가요.
- **처음 보는 몸짓**: 고양이가 어떤 몸짓을 처음 보여 주면 화면 아래에 그 뜻이 한 줄 떠요. 천천히 눈 깜빡이기는 고양이식 '좋아해', 꾹꾹이는 아기 고양이 때처럼 편하고 행복하다는 뜻, 배를 드러내고 자는 건 여기가 아주 안전하다는 뜻이에요. 그 밖에 골골송, 손가락에 볼 비비기, 더 해 달라고 조르기, 살짝 깨물기, 발라당, 꼬리를 바짝 세운 인사, 소리 없는 야옹, 플레멘, 발톱 갈기, 기둥에 볼 비비기, 등 돌리고 삐지기, 채터링, 빈 곳 빤히 보기, 갸웃, 우다다, 블렙, 식빵 자세, 당신이 보는 곳으로 따라와 같이 보기까지 스물세 가지예요. 몸짓마다 딱 한 번, 다른 안내가 떠 있지 않을 때 1분 반에 하나 이하로만 떠서, 고양이 말을 천천히 하나씩 배우게 돼요(더 중요한 안내가 바로 덮어 버려 못 읽었으면 다음에 다시 알려 줘요).

## 고양이의 하루

- 침대에서 자고, 깨면 기지개·하품·그루밍을 하고(기지개를 켜다 앞발을 번갈아 당기며 러그에 발톱을 사각사각 긁기도 하고, 옆으로 서 있을 땐 이어서 뒷다리도 하나씩 뒤로 쭉 뻗어요), 당신 앞에 와서 앉아 당신을 올려다볼 때면 가끔 소리 없이 입만 '야옹' 하고 벙긋해요(좋아하는 사람에게만 하는 고양이식 인사예요. 많이 믿으면 이어서 천천히 눈을 깜빡여요). 방을 돌며 몬스테라 화분·라디에이터·털실·책 더미의 냄새를 맡아요(가끔은 냄새를 맡다 말고 고개를 들어 당신 쪽으로 돌리고, 윗입술을 말아 올린 채 입을 반쯤 벌리고 눈을 가늘게 뜬 '플레멘' 표정으로 한참 멍하니 있어요. 그 냄새를 입으로 맛보는 중이에요. 가다가 가끔 멈춰 서서 고개를 들고 뭔가를 바라보다 다시 가요. 발소리도 마룻바닥에선 톡톡, 러그 위에선 폭신하게 달라요). 기분이 좋으면 램프 기둥에 볼을 비비며 천천히 지나가요(제 것이라는 표시예요): 고개를 기둥 쪽으로 돌려 기울이고 눈을 지그시 감은 채 볼부터 목, 옆구리까지 쓸고 지나가고, 꼬리가 기둥을 휘감듯 스쳐요. 가끔은 작게 트릴을 하고, 돌아서 반대쪽 볼로 한 번 더 비벼요. 방 왼쪽 벽 앞엔 삼줄을 감은 스크래쳐가 서 있어요(가로 화면이나 태블릿에선 늘 보이고, 휴대폰에선 고양이가 그쪽으로 가면 화면이 따라가요): 고양이 침대와 같은 청록 카펫 받침과 꼭대기 판, 줄 끝에 매달린 분홍 방울. 고양이는 하루에도 몇 번 그 앞에 가서(가끔은 밑동부터 킁킁 냄새를 맡고) 뒷발로 일어서 앞발을 높이 걸고, 등을 길게 뻗은 채 앞발을 번갈아 박박 긁어내려요. 눈은 반쯤 감고 꼬리는 높이, 긁을 때마다 삼줄이 거칠게 찢기는 소리가 나고 기둥이 살짝 흔들리며 방울이 대롱대롱 흔들려요. 마지막엔 두 앞발로 한 번 길게 쭉 당기고 내려와 그 옆에 앉아서, 당신 쪽을 돌아봐요(믿는 사이면 천천히 눈을 깜빡여요). 낮잠에서 깨어나면 기지개 대신 스크래쳐로 가서 쭉 늘어나기도 하고, 당신이 돌아와 무척 반가울 때도 인사를 마치고 가끔 스크래쳐로 달려가 신나게 긁어요(집사가 돌아오면 고양이들이 흔히 그래요). 스크래쳐 꼭대기 판 앞에는 긴 줄에 분홍 방울이 매달려 있어서, 고양이가 가끔 그 옆에 앉아 눈을 동그랗게 뜨고 꼬리 끝을 까딱이다가 앞발로 툭 쳐요. 방울이 이리저리 흔들리면 고개로 따라가다가 다가올 때 또 툭(가끔은 헛손질), 몇 번 놀고 나면 흔들림이 잦아드는 걸 보다가 당신을 돌아봐요. 가끔은 스크래쳐 아래에서 엉덩이를 낮추고 꼭대기를 한참 올려다보다가 훌쩍 뛰어올라(착지할 때 기둥이 흔들려요) 빙 돌아 식빵 자세로 앉아요. 꼬리는 판 가장자리로 늘어뜨려 끝을 이따금 까딱이고, 높은 데서 방을 이리저리 내려다봐요. 졸리면 거기서 그대로 졸고(밤엔 더 오래 머물러요), 내려올 땐 몸을 낮춰 착지할 곳을 내려다본 뒤 폴짝 뛰어내려요. 위에 있을 때 밥 먹으러 갈 때가 되거나 레이저 점이 보이면 바로 내려와요.
- 해가 들면 가끔 바닥의 햇살 자리에 가서 한참 누워 있어요. 해가 움직여 누운 자리가 그늘이 되면 일어나 햇살을 따라 자리를 옮겨요. 난방철(10월 말~4월 초)엔 라디에이터 앞 바닥에 가서 몸을 녹이며 한참 엎드려 있기도 해요. 햇살 자리나 라디에이터 앞에서 졸음이 오면 침대로 가지 않고 그 자리에서 잠들었다가, 깨면 잠시 뒤 침대로 돌아가거나 그 근처에서 계속 뒹굴어요.
- 기분이 좋으면 털실 공을 가지고 놀아요: 낮게 엎드려 노려보다 엉덩이를 씰룩이고 덮친 뒤 앞발로 툭툭. (덮치기 전 씰룩임은 처음엔 작고 느리다가 점점 빠르고 커지며 감아올려요.) 공을 톡 치면 굴러가고, 깨어 있으면 쫓아가요. 그냥 걸어가다 발에 공이 걸려도 공이 데굴 굴러 길 옆으로 비켜나고, 고양이 눈이 그 공을 따라가요.
- 레이저 포인터의 빨간 점이 나타나면 동공이 확 커지고 귀가 앞으로 쫑긋, 고개가 점에 꽂혀요. 가만히 있거나 살살 움직이는 점엔 바닥에 바짝 엎드려 살금살금 다가가 엉덩이를 씰룩이다 덮치고, 두 앞발로 꾹 누른 채 앞발 하나를 살짝 들어 그 밑을 들여다봐요(점은 발등 위에서 빛나고 있죠). 휙 달아나는 점은 전력으로 쫓아가며 급히 꺾을 때 발톱이 마룻바닥을 긁어요. 벽이나 화분, 라디에이터에 비추면 뒷다리로 일어서서 앞발로 톡톡 치고, 손이 안 닿을 만큼 높으면 그 밑에서 엉덩이를 씰룩이다 펄쩍 뛰어올라요(몇 번 해 보고 안 되면 앉아서 올려다보며 이빨을 딱딱거려요). 창턱에 비추면 창턱 끝에 앞발을 걸치고 서 있다가 뛰어올라 쫓아다니는데, 그러다 연필이나 김이 오르는 찻잔이 바닥으로 떨어지기도 해요. 찻잔이 쨍그랑 깨지면 바닥에 있던 고양이는 펄쩍 뛰며 털을 곤두세우고 달아났다가, 몸을 낮추고 한참 노려본 뒤 살금살금 다가가 조각 냄새를 맡고 앞발로 하나 건드려 봐요(차 웅덩이가 바닥에 번지고, 김도 더는 안 나요). 책 더미에 비추면 책 위로 덮쳐요. 점이 사라지면 그 자리를 멍하니 보다가 두리번두리번, 그러다 당신을 쳐다보며 야옹 하거나 트릴을 해요. 점을 고양이 몸에 비추면 그것도 잡아야 할 것이 돼요: 엉덩이나 꼬리에 비추면 고개를 뒤로 돌리고 몸을 둥글게 말아 제 꼬리를 쫓아 뱅글뱅글 돌다가 앉아서 그 자리를 핥고, 앞발에 비추면 발을 내려다보며 들어 올려 털고 다른 발로 톡톡, 옆구리에 비추면 돌아보며 핥고, 머리에 비추면(보이지 않으니) 고개를 털고 귀를 쫑긋거려요. 실컷 쫓고 나면 지쳐서 그 자리에 엎드려 눈으로만 좇고, 코앞에 오면 귀찮은 듯 앞발만 내밀어요. 신나게 논 날은 낮잠도 조금 일찍 와요.
- 당신을 좋아하는 고양이는 가끔 선물을 가져와요: 방 어딘가의 회색 펠트 장난감 쥐한테 가서 입에 물고, 고개와 꼬리를 자랑스럽게 든 채 당신 앞까지 가져와 발치에 툭 내려놓고는, 앉아서 당신을 올려다보며 "이것 봐" 하듯 야옹(또는 트릴) 하고 천천히 눈을 깜빡여요. 그 쥐를 톡 치면 방 안쪽으로 포물선을 그리며 날아가 톡 떨어져 미끄러지는데, 놀고 싶은 고양이는 달려가 덮쳐서 물고 다시 가져오기도 해요(물어오기 놀이). 당신을 믿을수록 자주 그래요.
- 장난감을 집어 들면(레이저 포인터의 딸깍, 낚싯대 방울의 딸랑) 깨어 있는 고양이는 그 소리를 알아듣고 귀를 쫑긋 세워 쳐다보고, 당신을 믿는 만큼 자주 작게 트릴을 해요.
- 놀다가 부딪히면 방도 대답해요: 몬스테라 화분에 대고 일어서거나 옆을 휙 지나가면 큰 잎이 사락사락 흔들리다 가라앉고, 창가에서 뛰어오르면 커튼이 봉에서 흔들렸다 돌아오고, 스탠드 기둥에 볼을 비비거나 부딪히면 스탠드가 받침 위에서 살짝 흔들리며 불빛도 같이 흔들려요. 평소엔 잎만 방 공기에 아주 살짝 흔들리고, 커튼은 봉에 단 고리에 걸려 창턱 바로 위까지 늘어져 있어요(창턱을 뚫고 내려가지 않아요). 주름은 고리 아래에서 촘촘하고 얕다가 아래로 갈수록 넓게 퍼지고 깊어지며, 폭도 제각각이라 판자가 아니라 천처럼 보여요. 밑단은 두 겹으로 접혀 조금 더 짙고, 앞으로 나온 주름마다 살짝 처져 물결져요.
- 깃털 낚싯대를 잡고 흔들면 깃털과 방울(딸랑)이 줄 끝에서 무게대로 흔들리고, 고양이 고개가 깃털을 따라가요. 바닥에 끌면 쫓아와 덮쳐서 두 앞발로 누르고 깨물어요(손끝에 느껴지고, 세게 당기면 빠져나와요). 손이 닿는 높이에서 흔들면 뒷발로 앉아 앞발로 휙 쳐서 깃털이 흔들려 날아가고, 조금 더 높으면 뒷다리로 서서 두 앞발로 짝짝 잡으려 하고, 더 높으면 제자리에서 펄쩍 뛰어올라요. 가끔은 공중에서 잡아채 끌어내려요. 잡으면 가끔 옆으로 벌러덩 누워 깃털을 두 앞발로 껴안고 깨물며 뒷발로 팡팡 차요(토끼차기). 낚싯대를 놓으면 바닥에 떨어지고, 그대로 두면 곧 흥미를 잃고 앉아서 세수를 해요. 바닥에 놓인 깃털을 혼자 가지고 놀 때도 있어요: 덮치고, 누르고, 툭 쳐서 미끄러뜨리고 다시 쫓다가 금방 시들해져요.
- 손가락으로 털실 공을 끌면 고양이 눈과 고개가 공을 따라가요. 멀어지면 달려가고, 움직이면 덮치고, 가까이 스치면 앞발로 후려쳐요. 잡히면 두 앞발로 꾹 누르고 깨물어서, 손가락을 당겨도 잠깐 빠져나오지 않아요(진동이 오는 기기에서는 손끝에 느껴져요). 계속 놀아 주면 지칠 때까지 놀고, 노는 동안은 잠들지 않으며 외로움이 줄어요.
- 밤엔 가끔 나방이 램프 주위를 팔랑팔랑 맴돌고, 따뜻한 계절 낮엔 파리가 창가를 윙윙 날다 창턱이나 유리에 앉아요. 고양이는 고개로 쫓으며 이빨을 딱딱거리고(채터링), 낮게 내려앉으면 살금살금 다가가 뒷다리로 일어서서 앞발로 후려쳐요.
- 가끔 앞발을 핥아 얼굴과 귀를 문지르며 세수를 해요(분홍 혀가 날름날름 보여요. 물을 마실 땐 혀끝을 아래로 말아 할짝할짝 떠먹어요). 앉아서 뒷발을 들어 귀 뒤를 박박 긁기도 해요(눈을 감고 고개를 발 쪽으로 기울인 채, 한두 번 쉬었다 다시 긁고), 다 긁으면 머리를 탈탈 털어요. 가끔은 작게 '취' 하고 재채기를 하고(가끔 두 번 연달아), 아무것도 없는 벽 위쪽을 귀를 세우고 동공을 키운 채 한참 뚫어지게 쳐다보다가 짹 하고 울기도 해요. 울 때는 소리에 맞춰 입이 움직여요(소리를 꺼도요).
- 눈 오는 날 창턱에 앉은 고양이는 내리는 눈송이를 하나하나 고개로 따라 내려가요(위로 휙, 아래로 스르르, 이쪽저쪽).
- 낮엔 가끔 참새 한 마리가 창밖 돌 턱에 내려앉아 콩콩 뛰고 턱을 쪼다 날아가요. 깨어 있는 고양이는 눈을 떼지 못하고 가끔 이빨을 딱딱거리고(채터링), 더 가까이 보려고 창턱으로 가기도 하지만, 고양이가 창에 다가오면 참새는 바로 날아가 버려요.
- 장난감 쥐를 너무 세게 던지면 가끔 라디에이터 밑 틈으로 쏙 들어가 버려요. 그러면 고양이가 다가가 엉덩이를 치켜들고 바닥에 머리를 대고 밑을 들여다보다가, 엎드려 앞발을 깊숙이 넣고 이리저리 더듬어요(발톱이 마룻바닥을 긁는 소리). 운 좋게 걸리면 쥐가 튀어나오고 바로 쫓아가 물어다 당신에게 가져와요. 몇 번 해도 안 되면 일어나 몸을 돌려 당신을 보고 앉아서 '야옹' 하고, 당신과 라디에이터를 번갈아 봐요(꺼내 달라는 거예요). 라디에이터나 그 밑을 톡 누르면 손이 쥐를 꺼내 방으로 굴려 주고, 고양이는 신나서 쫓아가요. 아무도 안 도와주면 한참 뒤 아쉬운 듯 한 번 돌아보고 포기해요.
- 창턱에 뛰어올라 창밖을 봐요. 아주 가끔은 점프가 모자라 앞발만 창턱에 걸치고 매달려요: 뒷발은 라디에이터 앞 허공에서 정신없이 버둥거리고(발톱 긁는 소리), 꼬리는 휘휘 돌고, 결국 엉덩이를 끌어올려 기어오르죠. 올라앉으면 고개를 돌려 누가 봤나 당신 쪽을 한 번 보고는, 아무 일 없었다는 듯 어깨 털을 재빨리 핥아요. 밤에는 도시 불빛을 보러 더 자주 올라가고, 그러다 졸리면 창턱 위에 식빵 자세로 엎드려 잠들어요(깨면 한동안 밖을 보다 내려와요). 비 오는 날엔 유리창을 타고 흘러내리는 빗방울을 고개로 따라가며 앞발로 톡톡 건드려요. 꼬리를 창턱 아래로 늘어뜨리고, 새가 지나가면 고개로 쫓으며 이빨을 딱딱거려요(채터링). 비 오는 날 더 자주 올라가요. 내려오기 전 방 쪽으로 돌아앉았다가, 가끔은 창턱 끝의 노란 연필을 한참 내려다보고 당신을 한 번 쳐다본 뒤 앞발로 톡… 톡… 밀어서 기어이 바닥으로 떨어뜨려요(딱 소리가 나요). 떨어지는 연필을 눈으로 좇고는 다시 당신을 봐요. 바닥의 연필을 톡 누르면 창턱에 다시 올려 둘 수 있어요. 창밖을 보다가 가끔은 옆에서 김이 오르는 찻잔에 코를 들이밀고 킁킁, 뜨거워서 움찔 물러나 눈을 찡그리고는 코를 핥고 도리도리 해요. 어떤 때는 피어오르는 김을 눈으로 좇다가 앞발로 휙 쳐 보고, 아무것도 안 잡히니 제 발을 내려다보며 고개를 갸웃, 발을 핥아요. 창턱 위 찻잔(김이 모락모락 올라요)도 연필과 마찬가지예요: 옆으로 몇 걸음 옮겨 앉아 찻잔을 보고, 당신을 보고, 톡… 톡… 마지막엔 쓱 밀어서 쨍그랑. 깨지는 소리에 자기도 움찔하고는 내려다본 뒤 태연하게 당신을 쳐다봐요. 밀기 직전에 빈 곳을 톡 치면 딱 걸려서 앞발을 든 채 얼어붙어 눈을 동그랗게 뜨고 당신을 봐요. 그다음은 그날 기분대로: 슬그머니 발을 거두고 창밖 먼 데를 보며 시치미를 떼거나, 당신과 눈을 맞춘 채로 그냥 쓱 밀어 버리거나.
- 가끔, 특히 해 질 녘과 밤에 갑자기 우다다를 해요. 엉덩이를 씰룩이다 꼬리를 세우고 침대 앞을 지그재그로 휙휙 내달리고(급히 꺾을 때 발톱이 바닥을 긁어요), 길에 털실이 있으면 차서 날려 버리고 그대로 털실 사냥에 나서기도 해요. 실컷 달리면 미끄러지듯 멈춰 당신 쪽을 보고 앉아, 아무 일 없었다는 듯 두리번거려요.
- 놀고 싶은데 할 게 없으면 가끔 제 꼬리를 쫓아요. 씰룩이는 꼬리 끝을 어깨 너머로 노려보다가 낮게 엎드려 빙글빙글 두세 바퀴 돌며 쫓고(꼬리는 늘 한 뼘 앞에서 휙 달아나요), 마침내 덮쳐서 앞발로 누르고 앙 깨문 다음, 당신 쪽을 보며 시치미 떼듯 앉아서 가슴털을 몇 번 핥아요.
- 사흘씩 번갈아 방 한쪽에 빈 종이 상자가 놓여요(들어가면 맞는 거예요). 고양이는 다가가 안을 들여다보고 폴짝 뛰어 들어가, 몸을 돌려 머리만 내민 채 식빵 자세로 앉아 있다가 그대로 졸기도 해요. 다 쉬면 몸을 돌려 폴짝 나와요.

## 생활과 건강

실제 시간으로 흘러갑니다. 앱을 닫아 둔 동안에도 고양이는 배고파지고, 밥을 먹으러 가고, 화장실을 쓰고, 돌아다닙니다.

- 가득 찬 밥그릇은 하루쯤 갑니다. 그릇이 비고 배가 고프면 당신을 보며 웁니다. 빈 밥그릇 옆에 가 앉아 당신을 올려다보기도 하고, 그렇게 한 번 졸랐는데도 몇 분째 밥이 없으면 다음엔 방 저편에서 당신 바로 앞까지 와서 꼬리를 세우고 야옹 한 다음, 밥그릇 쪽으로 걸어가다 중간에 멈춰 어깨 너머로 당신을 돌아보며 한 번 더 울어요(따라오라는 거예요).
- 밥과 물을 전혀 주지 않으면 약 2일 뒤 아프기 시작하고(색이 바래고, 호흡이 얕아지고, 반응이 줄고, 등을 둥글게 웅크린 채 고개를 몸쪽으로 푹 숙이고 있어요) 약 3~4일 뒤 죽습니다. 다시 챙겨 주면 회복해요.
- 더러운 화장실은 쓰지 않으려 하고, 다른 곳에 실수를 하며 당신을 덜 믿게 됩니다.
- 배가 고픈데(목이 마른데) 그릇이 비어 있으면, 그릇으로 가서 고개를 숙여 냄새를 맡아 보고, 빈 그릇 옆에 돌아앉아 당신을 올려다보며 울어요(오래 기다렸으면 애처롭게). 그 사이 밥을 주면 바로 먹으러 가요.
- 손길에 짜증이 났다가 손이 떠나면, 가끔 그 자리에서 돌아서 등을 보이고 앉아요. 귀를 옆으로 젖힌 채 있다가 한 번 어깨 너머로 힐끗 돌아보고, 마음이 풀리면 다시 제 할 일을 해요.
- 손길이 싫어 짜증이 나면, 처음 한 번은 왜 싫었는지(털을 거꾸로 쓸었는지, 꼬리·배·발을 만졌는지, 너무 빨랐는지, 너무 오래였는지) 화면 아래에 알려 줘요.
- 기분이 상해 도망가면 방 끝 구석(스크래쳐 옆이나 화장실 너머)으로 성큼성큼 가서, 당신에게 등을 돌리고 식빵 자세로 삐져 있어요. 귀는 뒤로 젖히고 꼬리 끝을 이따금 탁탁 치며, 가끔 어깨 너머로 힐끗 돌아보고는 다시 고개를 돌려요. 오래 삐져 있으면 그 구석에서 등을 돌린 채 꾸벅꾸벅 졸아요(천둥이 쳐도 움찔할 뿐 자리를 뜨지 않아요). 화면이 따라가고, 둘러보면 언제든 찾을 수 있어요. 그때 만지면 귀를 납작하게 하고 꼬리를 휙 치며 작게 그르렁거려 손을 털어 내고(손끝에 톡), 자꾸 만지면 일어나 반대편 구석으로 가 버리고 더 오래 삐져요. 몇 분에서 수십 분 지나면 스스로 풀려 다시 방을 돌아다니고, 당신을 믿는 고양이라면 조금 기다렸다가 살며시 만졌을 때 돌아앉아 천천히 눈을 깜빡이며 화해하고, 당신 앞까지 와서 인사해요. 삐져 있을 때 빈 곳을 두드리면 귀를 돌리고 어깨 너머로 힐끗 돌아봐요(당신을 아주 믿는 고양이면 곧 마음이 풀려요). 만난 지 며칠 안 된 고양이는 아직 서로를 알아 가는 중이라 몇 분이면 풀려요.
- 밥그릇·물그릇·화장실은 방 안에 있어서, 고양이가 걸어가 먹고 마시고 볼일을 보는 모습이 보이고 그릇이 줄어들어요(먹는 동안 만지면 귀를 한 번 털고 계속 먹어요). 다 먹으면 세수를 하고 침대로 돌아가고, 화장실에서 나오면 가끔 우다다 방을 한 바퀴 달려요. 고양이는 절대 방 밖으로 나가지 않아서, 앱을 닫아 둔 사이 밥을 먹으러 가 있었으면 그릇 앞에서, 삐져 있었으면 구석에서, 돌아다니던 중이었으면 방 어딘가에서 만나요. (그림 고양이에서는 창밖이라 소리로만 전해집니다.)

### iOS · Android에서

같은 코드가 모바일 브라우저(PWA로 홈 화면에 추가)와 네이티브 앱(Capacitor) 모두에서 그대로 돌아갑니다.

- 터치는 포인터 이벤트로 받아서 iOS Safari·Android Chrome·데스크톱 마우스가 같은 동작을 해요. 화면 확대, 길게 누를 때의 메뉴, 텍스트 선택은 모두 꺼 두었어요. 시스템이 제스처를 가로채면(가장자리 스와이프 등) 들고 있던 장난감을 놓은 것으로 처리해요.
- 소리는 Safari 규칙대로 손가락을 뗄 때 켜지고, 전화나 백그라운드로 끊긴 뒤에도 다음 터치에 다시 살아나요. iOS에선 방의 소리답게 다른 앱의 음악과 섞이고 무음 스위치를 따라요.
- 진동: 네이티브 앱은 Taptic Engine/진동 모터로 다 느껴지고, Android 브라우저(아티팩트 포함, 그 화면을 한 번 톡 한 뒤부터)는 vibrate로 골골송과 손끝 반응이 전해져요(폰 모터가 못 느낄 만큼 짧지 않게, 톡은 18ms 이상, 골골송은 24ms씩 웅웅). iPhone의 웹(Safari, 아티팩트 포함)은 vibrate가 없고, iOS 26.5부터는 스크립트로 진동을 낼 길도 애플이 막았어요. 그래서 iPhone 웹에선 화면 위에 보이지 않는 층을 깔아, 손가락이 톡 두드린 바로 그 순간에만 시스템 스위치의 '틱'을 내요: 고양이를 톡 건드리거나 코를 톡, 삐진 고양이를 만졌을 때, 램프·라디오를 켜고 끌 때. 쓰다듬는 동안의 골골송 진동은 iPhone 웹에선 낼 수 없어요(소리로만 들리고, 무음 모드면 소리도 안 나요). iOS 18~26.4에선 쓰다듬는 손가락 아래로 골골송이 '틱틱'으로 전해지고, 고양이 발이 손끝에 닿는 '톡'처럼 터치 밖에서 생긴 진동은 손가락이 다음에 움직이는 순간에 전해요.
- 기울이기: 휴대폰의 기울기(자이로)는 지금 쥔 각도를 기준으로 재고, 그대로 쥐고 있으면 몇 초에 걸쳐 다시 가운데로 돌아와요. 가로 화면에선 축을 화면에 맞춰 바꿔요. Android는 바로 되고, iOS는 처음 '흔들어서 사료 주기' 안내 때 묻는 동작 권한을 허용하면 함께 켜져요. 고양이를 만지는 동안(가까이 다가간 화면)과 '동작 줄이기' 설정에선 움직이지 않아요.
- 라디오가 켜져 있는 동안은 화면이 꺼지지 않아요(lofi 방송처럼 책상 위에 켜 두기 좋게). 브라우저는 화면 깨우기 잠금(Screen Wake Lock)을 쓰고, 앱으로 빌드할 땐 keep-awake 플러그인(@capacitor-community/keep-awake)을 넣으면 그걸 써요. 라디오를 끄면 다시 평소처럼 꺼져요. 아무도 만지지 않은 채 몇 분이 지나면 초당 20장으로 더 느긋하게 그려 배터리를 아껴요.
- 네이티브 Android에선 뒤로 가기 버튼이 크레딧을 닫거나 앱을 내려 둡니다(고양이는 꺼지지 않아요). 앱이 백그라운드로 가면 상태를 저장하고 알림을 예약해요.
- 홈 화면에 추가한 웹앱(PWA)은 서비스 워커로 방을 저장해 두어 오프라인에서도 열리고, 알림도 서비스 워커를 통해 띄워요(Android Chrome은 이 방법으로만 알림을 보여 줘요). iOS에선 상태 표시줄 아래까지 방이 꽉 차게 보이고, 시작 화면은 방의 벽 색이에요.
- 레이저 포인터를 든 채로도 화면을 톡 치면 빈 곳을 두드린 것과 같아서, 두 번 톡톡 두드리면 자는 고양이를 깨울 수 있어요. 데스크톱에선 `Esc`로 내려놓아요.
- 고양이가 잠들었거나 제자리에 가만히 있고 아무것도 만지지 않을 땐 초당 30프레임으로 그려서 배터리를 아끼고(걷거나 놀거나, 폰을 기울여 시점이 움직이는 동안엔 60프레임), 고주사율 화면에서도 60프레임을 넘기지 않아요.
- 방에서 움직이지 않는 것들(책, 늘어진 화분의 잎, 라디에이터 기둥, 창틀 등 177개)은 시작할 때 생김새가 같은 것끼리 합쳐서 16개로 그려요. 폰 그래픽이 가장 느린 그리기 호출이 프레임마다 약 380번에서 186번으로 줄어요(`tools/soak.mjs`가 합친 것들이 정말 한 번도 움직이지 않는지 확인해요).
- 그림 한 칸(아트 픽셀)은 화면 약 1.7포인트예요. 화면 픽셀이 포인트당 3개인 폰이면 5×5 화면 픽셀이 한 칸이라, 고양이 눈·코·수염이 또렷하면서도 칸이 보이는 픽셀아트로 남아요(예전엔 6×6). 칸 수가 1.44배가 되지만 폰에서 이 그림은 작은 버퍼(390포인트 폰에서 236×509칸)라 화면 전체 픽셀의 4% 남짓이고, 그리기 호출과 삼각형 수는 그대로예요. 태블릿이나 가로로 든 폰에서도 세로 폰보다 촘촘해지지는 않아요. 비교용으로 `?px=2.1`(예전 크기)이나 `?px=1.4`(더 촘촘하게)를 붙여 볼 수 있어요. 그래도 버거운 폰을 위해, 화면에 움직임이 있는데 초당 25프레임 아래로 몇 초 넘게 떨어지면 그 자리에서 예전 크기(2.1포인트)로 바꾸고 다음에 열 때도 그 크기로 시작해요(아이폰 저전력 모드의 초당 30프레임 제한이나 잠깐의 끊김에는 반응하지 않아요. 바꾸는 건 손가락을 떼고 화면이 고양이에게서 물러난 다음이라, 쓰다듬는 도중에 그림이 갑자기 바뀌지 않아요).
- 촘촘해진 칸에 맞춰 물건도 더 공들여 칠해요. 라디에이터 기둥, 찻잔, 화분, 밥그릇·물그릇, 호박 같은 둥근 물건은 픽셀 화가가 칠하듯 밝은 띠 한 줄, 중간 톤, 그림자 쪽을 색 단계로 나눠 칠해서 둥근 맛이 살아요. 찻잔은 위에서 내려다보이는 테두리와 그 안의 차, 파란 유약 띠가 보이고, 호박은 골이 패여 있어요. 창틀과 창살은 밝은 낮 하늘 앞에서 한 단계 어둡게, 하늘과 맞닿은 가장자리는 역광을 받아 한 줄 밝게 그려요(밤엔 그대로). 찻잔의 김은 칸이 촘촘해져도 방에서 같은 높이로 올라가요. 창턱의 라디오는 모서리가 둥근 나무 상자라 위·왼쪽 모서리가 빛을 받고 오른쪽·아래 모서리는 그늘지며, 스피커 천 둘레엔 더 짙은 나무 테가 있어요. 낮에 꺼져 있는 꼬마전구는 저마다 켜질 때 색을 옅게 머금은 유리예요.

### claude.ai 아티팩트로 띄우기

`node tools/artifact.mjs <폴더>`는 앱을 아티팩트용 HTML 한 장(약 2.7MB)으로 만들어요. 스크립트와 픽셀 글꼴, 불러오는 화면 그림, 고양이 모델까지 페이지 안에 모두 들어가요(아티팩트는 외부 스크립트도 .bin 파일도 내주지 않거든요). 아티팩트 화면에서는 알림·기울기 센서·서비스 워커를 쓸 수 없어서, 이 빌드는 알림 허용을 묻지 않고 기울기 권한도 청하지 않아요. 고양이와 방의 상태는 그 아티팩트 주소의 브라우저 저장소에 따로 남아요.

### 폰 앱으로 빌드 (iOS / Android)

```bash
npm run build
npx cap add android      # 또는: npx cap add ios  (macOS + Xcode 필요)
npx cap sync
npx cap open android     # Android Studio 에서 실행/서명
```

Android 알림 아이콘으로 `android/app/src/main/res/drawable/ic_stat_cat.png`(흰색 실루엣)를 넣으면 됩니다. `public/icons/badge-96.png`를 그대로 써도 됩니다.

앱 아이콘(`public/icons`)은 앱의 픽셀아트로 그렸어요: 랩이 고양이를 64×64 아트 픽셀로 그리고, 노을 진 창가 앞에 앉혀 정수 배로 키웁니다(안드로이드 원형 마스크용은 고양이를 조금 작게). 알림 배지는 같은 고양이 머리의 실루엣이고, 앱을 여는 동안 보이는 화면에도 같은 그림(`art-64.png`)이 벽 색 위에 정수 배로 떠요. 다시 만들 땐 개발 서버를 켜고 `node tools/icons.mjs`. 네이티브 프로젝트의 아이콘은 `npx @capacitor/assets generate`에 `icon-512.png`를 넘기면 됩니다.

```
             공기 중의 빛줄기) → 빛나는 것의 은은한 번짐(bloom) → 정수배 크기로 화면에 찍기.

             커튼·스탠드 같은 세로선이 계단 없이 곧게 서요
src/pixel    픽셀 앱: 방(창밖의 층층이 도시와 시차, 비, 라디오, 초, 라디에이터), 고양이의 일상 행동
             (냄새 맡으러 다니기, 햇살 자리에 눕기), 고양이를 따라가는 카메라와 쓰다듬을 때의 클로즈업.
             chase.ts: 레이저 점 쫓기(살금살금·덮치기·전력 질주·벽 타기·창턱 점프), 깨지는 소리에 놀라기.
             nerves.ts: 고양이의 시각과 작은 신경망(눈 위치에서의 시야·가림·지연·잔상, 대상마다 하나인

             whim.ts: 혼자 있을 때의 욕구와 의도(기분과 눈길로 세지는 욕구, 하기 전에 먼저 바라보기).
             mind.ts: 고양이의 마음 창(고양이 눈에서 본 방, 신경망의 반응과 주목, 욕구와 의도).

             room.ts: 창턱 위 찻잔이 밀려 넘어지고 깨지는 물리, 줄 끝 깃털의 진자 운동, 긁힐 때 흔들리는
             스크래쳐와 대롱거리는 방울
tools/cat3d  Fripouille 모델을 우리 뼈대에 리깅, 입 안·이빨, 픽셀용 털 재질 텍스처를 만드는 스크립트
src/render   (그림 고양이) WebGL2 렌더러: 메시 변형(호흡, 머리, 귀, 꼬리, 꾹꾹이, 털 반응), 절차적 눈, 그림자, 모션 블러

             (stills.mjs 시간대별 스틸, appreel.mjs 게임 시간으로 찍는 GIF, lofirender.mjs 음악 미리 듣기,
             soak.mjs 몇십 분의 삶을 빠르게 돌려 보는 점검, touch_e2e.mjs 휴대폰처럼 실제 터치 이벤트로
             라디오·크레딧·물 주기·쓰다듬기·레이저 포인터·낚싯대를 차례로 확인)
```

`tools/build_layers.py`가 원본 그림 한 장을 배경과 분리하고, 몸·꼬리 끝·머리·양쪽 귀 레이어로 나누고, 움직일 때 드러나는 부분(턱 밑, 귀 뒤, 꼬리 아래)을 채워 `public/assets/`에 내보냅니다. 다른 그림으로 바꾸려면 이 스크립트의 다각형과 `rig.json` 기준점을 새 그림에 맞추면 됩니다.

## 알아 둘 점

- **그림 저작권**: 지금 고양이는 첨부해 주신 그림을 그대로 씁니다. 그림은 다른 작가의 작품일 수 있으니, 앱을 공개 배포하기 전에 사용 권리를 확인하거나 직접 그리거나 의뢰한 그림으로 바꿔 주세요.
- **그림 고양이의 움직임 한계**: 그림이 한 장(웅크려 자는 자세)뿐이라 걷기·먹기 자세는 그리지 않았습니다. 떠날 때는 휙 사라지고(모션 블러), 돌아올 때는 초점이 맞듯 나타나며, 밥·물·화장실은 창밖 소리로 표현합니다. 같은 화풍의 추가 자세 그림이 있으면 같은 방식으로 리그에 붙일 수 있어요.
- **3D 고양이 모델 출처**: 픽셀아트 고양이는 guillaume bolis의 ["3d modelling my cat: Fripouille"](https://sketchfab.com/3d-models/3d-modelling-my-cat-fripouille-0ab14bf98e754f8d90fe1bf1c84ca66c) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))을 우리 뼈대에 다시 리깅하고, 털을 픽셀아트용 몇 가지 평면 색으로 단순화하고(몸과 꼬리, 정수리에서 목덜미까지의 태비 줄무늬는 띠로 새로 그림), 눈을 절차적 눈으로 바꾸고, 픽셀아트에서는 얼굴이 읽히도록 머리를 조금(1.15배), 눈을 1.3배 크게 그려서 씁니다. 앱을 배포할 때는 앱 안 크레딧에도 이 출처와 "수정함"을 적어야 합니다. 변환은 `tools/cat3d/fripouille.py`가 하고(`public/cat3d/fri.bin`), 픽셀용 털 재질만 다시 만들 때는 `tools/cat3d/recoat.py`를 씁니다. 출처 문구는 파일 머리에도 들어 있습니다.
- **글꼴**: 안내 문구·불러오는 화면·크레딧은 이민서(quiple)의 픽셀 글꼴 [Galmuri](https://github.com/quiple/galmuri)(SIL OFL 1.1)로 씁니다. 앱이 쓰는 글자만 추린 서브셋(약 9 KB)을, 라이선스가 '예약된 글꼴 이름'에 요구하는 대로 이름을 바꿔(Window Pixel) 넣었고, 라이선스 전문은 `public/fonts/OFL.txt`, 크레딧에도 출처를 적었어요. 글꼴의 한 픽셀이 화면 픽셀의 정수 배가 되도록 크기를 맞춰서(배율 2.625인 폰에선 3픽셀) 글자가 번지지 않아요. 새 문구에 없는 글자가 생기면 테스트가 알려 주니 `python3 tools/font_subset.py`를 다시 돌리면 돼요(`pip install fonttools brotli` 필요).
- **소리**는 모두 실시간 합성이라 실제 녹음보다 덜 사실적일 수 있습니다. `src/audio/audio.ts`의 뱅크를 녹음 파일로 바꿀 수 있습니다.
- iPhone의 웹(Safari·아티팩트)은 웹 진동 API가 없고 iOS 26.5부터는 스크립트로 진동을 낼 수도 없어서, 연속 진동인 골골송은 Android 브라우저와 네이티브 앱에서만 느껴집니다(iPhone 웹에선 손가락으로 톡 두드릴 때의 짧은 '틱'만 전해져요). iPhone에서 쓰다듬는 촉감까지 원하면 네이티브 앱으로 빌드해야 해요.
