# 창가의 고양이

화면을 창문 삼아 그 너머에 사는 고양이 한 마리. 버튼도, 메뉴도 없습니다. 앱을 열면 빈 종이 위에 그림 속 고양이가 잠들어 있고, 손가락으로 쓰다듬고 밥과 물을 챙기며 서로 믿음을 쌓아 갑니다.

## 고양이와 지내는 법

| 하고 싶은 것 | 하는 법 |
| --- | --- |
| 쓰다듬기 | 고양이 위를 손가락으로 천천히 쓸기. 털 결(머리 → 등 → 꼬리) 방향이 좋아요 |
| 부르기 / 관심 끌기 | 빈 곳을 톡 두드리기, 두 번 두드리면 노크 |
| 사료 주기 | 휴대폰 흔들기 (사료 봉지 소리), 또는 빈 곳을 좌우로 빠르게 문지르기 |
| 물 주기 | 빈 곳을 길게 누르고 있기 (누르는 동안 물이 따라져요) |
| 화장실 모래 치우기 | 빈 곳을 아래로 쓸어내리기 |
| 작별 인사 / 새 고양이 | 숨을 멈춘 고양이를 오래 누르기 → 빈 창가를 오래 누르기 |

필요한 순간에만 화면 아래에 옅은 안내 문장이 잠깐 나타납니다. 데스크톱에서는 `F`(사료), `W`(누르고 있으면 물), `L`(모래)도 됩니다.

## 고양이의 마음

- **부위별 호불호**: 턱·볼·머리·목덜미는 좋아하고, 꼬리·발·배는 싫어해요. 고양이마다 성격(좋아하는 부위, 참을성, 목소리)이 조금씩 다릅니다.
- **결과 속도**: 털 결을 거스르거나 너무 빠르게 문지르면 싫어하고, 거슬러 쓴 털은 한동안 헝클어진 채 남아요.
- **과자극**: 좋아하는 곳도 너무 오래 만지면 꼬리 끝이 까딱이고, 등 가죽이 꿈틀거리고, 귀가 젖혀지다 결국 하악질과 솜방망이, 그래도 계속하면 도망갑니다.
- **기분이 좋으면** 골골송(소리 + 지원 기기에서는 진동), 눈을 지그시 감기, 손에 머리를 기대기, 꾹꾹이, 천천히 눈 깜빡이기(고양이식 애정 표현).
- **신뢰도**는 모든 접촉으로 조금씩 변해요. 낮으면 잘 놀라고 경계하며 하악질이 빨라지고, 높으면 먼저 다가와 트릴로 인사하고 알림으로 당신을 부릅니다.
- **잠**: 대부분 자고, 가끔 실눈을 떠서 당신을 확인하고, 한숨을 쉬고, 귀를 움찔해요. 새벽과 해질녘에 더 활발합니다.
- **눈**: 그림 위에 실시간으로 그려지는 눈이 당신(화면)을 보거나 손가락을 따라가요. 동공은 빛·흥분·공포에 따라 커지고 줄어들고, 눈동자에는 이 창(화면)이 비쳐요.

## 생활과 건강

실제 시간으로 흘러갑니다. 앱을 닫아 둔 동안에도 고양이는 배고파지고, 밥을 먹으러 가고, 화장실을 쓰고, 돌아다닙니다.

- 가득 찬 밥그릇은 하루쯤 갑니다. 그릇이 비고 배가 고프면 당신을 보며 웁니다.
- 밥과 물을 전혀 주지 않으면 약 2일 뒤 아프기 시작하고(색이 바래고, 호흡이 얕아지고, 반응이 줄어요) 약 3~4일 뒤 죽습니다. 다시 챙겨 주면 회복해요.
- 더러운 화장실은 쓰지 않으려 하고, 다른 곳에 실수를 하며 당신을 덜 믿게 됩니다.
- 기분이 상해 도망가면 몇 분에서 수십 분 뒤 돌아와요. 발소리가 먼저 들립니다.
- 창밖(밥그릇, 화장실)은 보이지 않고 소리로만 전해집니다. 바삭바삭 씹는 소리, 물 핥는 소리, 모래 긁는 소리.

## 알림

앱이 닫혀 있는 동안 고양이가 필요로 할 것을 미리 계산해 알림을 예약합니다(배고픔, 물, 화장실, 아픔, 외로움). 밤 11시~아침 8시에는 위급할 때만 울립니다.

- **네이티브 앱(권장)**: Capacitor 로컬 알림으로 앱이 꺼져 있어도 정확히 옵니다.
- **웹/PWA**: 브라우저가 백그라운드 탭을 살려 두는 동안만 보낼 수 있습니다. 확실한 알림은 네이티브 빌드에서 쓰세요.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173  (?debug 를 붙이면 상태 패널과 시간 빨리감기)
npm test           # 생존/알림 예측 시뮬레이션 테스트
npm run build      # dist/ 에 정적 사이트 (PWA)
```

### 폰 앱으로 빌드 (iOS / Android)

```bash
npm run build
npx cap add android      # 또는: npx cap add ios  (macOS + Xcode 필요)
npx cap sync
npx cap open android     # Android Studio 에서 실행/서명
```

Android 알림 아이콘으로 `android/app/src/main/res/drawable/ic_stat_cat.png`(흰색 실루엣)를 넣으면 됩니다. `public/icons/badge-96.png`를 그대로 써도 됩니다.

## 구조

```
src/render   WebGL2 렌더러: 메시 변형(호흡, 머리, 귀, 꼬리, 꾹꾹이, 털 반응), 절차적 눈, 그림자, 모션 블러
src/rig      리그 데이터, 털 스프링 격자(손가락이 털을 끌고 지나가면 되돌아옴), 애니메이터
src/sim      욕구/건강 시뮬레이션, 고양이의 뇌(기분·신뢰·반응), 부위 지도, 알림 예측
src/audio    녹음 없이 합성한 소리 (골골송, 트릴, 야옹, 하악, 그르렁, 사료, 물, 모래, 씹는 소리 등)
src/input    터치 제스처, 흔들기 감지
tools/       그림 → 레이어 파이프라인 (Real-ESRGAN 업스케일, 알파 매팅, LaMa 인페인팅), 스크린샷 도구
```

`tools/build_layers.py`가 원본 그림 한 장을 배경과 분리하고, 몸·꼬리 끝·머리·양쪽 귀 레이어로 나누고, 움직일 때 드러나는 부분(턱 밑, 귀 뒤, 꼬리 아래)을 채워 `public/assets/`에 내보냅니다. 다른 그림으로 바꾸려면 이 스크립트의 다각형과 `rig.json` 기준점을 새 그림에 맞추면 됩니다.

## 알아 둘 점

- **그림 저작권**: 지금 고양이는 첨부해 주신 그림을 그대로 씁니다. 그림은 다른 작가의 작품일 수 있으니, 앱을 공개 배포하기 전에 사용 권리를 확인하거나 직접 그리거나 의뢰한 그림으로 바꿔 주세요.
- **움직임의 한계**: 그림이 한 장(웅크려 자는 자세)뿐이라 걷기·먹기 자세는 그리지 않았습니다. 떠날 때는 휙 사라지고(모션 블러), 돌아올 때는 초점이 맞듯 나타나며, 밥·물·화장실은 창밖 소리로 표현합니다. 같은 화풍의 추가 자세 그림이 있으면 같은 방식으로 리그에 붙일 수 있어요.
- **소리**는 모두 실시간 합성이라 실제 녹음보다 덜 사실적일 수 있습니다. `src/audio/audio.ts`의 뱅크를 녹음 파일로 바꿀 수 있습니다.
- iOS Safari는 웹 진동을 지원하지 않아 골골송 진동은 Android 브라우저와 네이티브 앱에서만 느껴집니다.
